SmartNF 로그인 이메일

이메일·비밀번호 변경 또는 탈퇴 후 기존 로그인은 종료됩니다. 다른 탭·기기의 로그인도 다음 요청부터 사용할 수 없습니다.

SNS 연결 상태

이 계정에 연결된 SNS가 없습니다.

현재 회원에 저장된 연결 상태입니다. SNS 추가 연결·해제나 별도로 가입한 계정 병합은 아직 제공하지 않습니다. SNS 제공자 측 앱 접근 권한 해제는 해당 서비스에서 별도로 관리합니다. SNS의 이메일·비밀번호는 해당 서비스에서 관리하세요.

로그인 이메일 변경

현재 비밀번호와 기존·새 이메일의 확인 코드가 모두 필요합니다. 코드는 10분간 유효하며 최대 5회 확인할 수 있습니다. 확인 전에는 로그인 이메일이 바뀌지 않습니다.

SNS 전용 계정에는 변경할 SmartNF 로그인 이메일이 없습니다.

메일 발송 설정 전입니다. 설정이 완료되면 이 화면에서 이메일 변경을 이용할 수 있습니다.

비밀번호 변경

SNS 전용 계정의 비밀번호는 해당 SNS에서 변경하세요.

12~64자, UTF-8 기준 72바이트 이내로 입력하세요.

회원 탈퇴

현재 개발 기능의 회원 탈퇴입니다. 건강정보·질환 상세·측정값·관리항목·일일 기록·개인 화면 구성·로그인 자격·SNS 연결을 삭제하고 표시 이름을 지웁니다. 최소 회원 식별자·탈퇴 상태·가입/건강정보 동의 이력은 남습니다. 완전한 익명화나 모든 보관본의 삭제 완료를 의미하지 않습니다.

건강정보만 지우려면 건강정보 저장 동의 철회를 이용하세요. 탈퇴 후 삭제한 건강기록은 재가입해도 복원되지 않습니다. 거래·결제 기능은 현재 이 처리 범위에 없습니다.

SNS 전용 계정은 공급자 본인 재확인 방식 연결 후 탈퇴를 제공합니다. 현재 이 화면에서는 탈퇴할 수 없습니다.

관리자 계정은 권한 이관 절차가 필요하므로 여기서 탈퇴할 수 없습니다. 운영용 보유기간·백업 삭제·거래 기록 보관 정책은 확정 전입니다.
