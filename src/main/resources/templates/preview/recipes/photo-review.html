레시피 참고 사진 검토

원본 페이지에서 음식 이름과 사진이 일치하는지, 출처·라이선스 정보가 유효한지 확인한 뒤 승인하세요.

사진 출처 연결 상태

공유마당 API: 상세 명세 확인 대기 · 현재는 확인한 사진 등록 방식으로 사용합니다.

  • Wikimedia Commons · 검색 사용 · 키 불필요

원문 검색에서 못 찾으면 로컬 LLM으로 대표 음식명을 제안받습니다. 제안 검증에 실패하면 기본 검색어를 사용합니다.

설정됨은 연결 성공을 뜻하지 않습니다. 실제 검색 결과와 오류는 아래 음식별 기록에서 확인하세요.

검토할 사진이 없습니다.

· 원본 확인 후 승인하면 참고 사진으로 표시됩니다.

최근 검색 기록

키 설정을 바꾼 뒤 대기열을 갱신하면 재검색 시간을 기다리지 않고 다음 점검 때 확인할 수 있습니다. 검색 제외·승인·검토 대기 사진은 유지합니다.

등록 사진 → 식품안전나라 → 포토코리아 → Wikimedia → Openverse 순으로 검색합니다. 키가 없는 출처는 건너뜁니다. 시작 1분 후 첫 점검, 이후 각 점검 완료 5분 뒤 최대 10개를 처리합니다.

사진 후보를 찾지 못한 음식은 1시간 간격으로 자동 검색합니다. 사진만 제외하면 다른 후보를 계속 검색하며, 검색 제외한 음식은 중단합니다. 제외를 해제하면 다음 자동 점검 때 다시 검색합니다.

표시할 검색 기록이 없습니다.
