식재료·가격 비교

장보기 재료에서 선택하거나 비교할 재료와 필요량을 입력하세요.

재료에 저장된 수량·단위를 사용합니다. 다른 단위는 확인한 수량을 별도로 입력하세요. g·mL·개·포장 단위는 근거 없이 자동 환산하지 않습니다.

1. 온라인 판매 사이트 바로가기

헬스케어와 같은 온라인 쇼핑몰 연결입니다. 재료명이 있으면 해당 검색 결과를, 없으면 사이트 홈을 새 창으로 엽니다. 직접 검색 링크이며 가격 자동 수집을 의미하지 않습니다.

2. 수집된 실제 판매상품

판매처의 상품명·포장량·판매가격을 비교하세요. KAMIS·참가격 기준 필요량 예상금액과 총예상금액은 내 장보기에서 확인합니다.

외부 자료 수집·검토 · 운영 설정

판매처에서 상품 가져오기

자료를 가져와 검토 후보로 표시합니다. 기존 식단·장보기·저장 상품은 자동으로 변경하지 않습니다.

검토 중인 내용이 있다면 아래 버튼으로 새 결과를 불러올 때 교체됩니다. 파일 업로드와 Python 수집기는 계속 사용할 수 있습니다.

수집 결과 불러오기·검토 (API / 크롤링·RPA / 전단 OCR)

Python 수집기가 만든 JSON을 선택하세요. 원문과 상품명·포장량·가격·기간·조건을 확인한 행만 본인 계정에 저장됩니다. 외부 페이지 공개 여부와 별도로 수집·재사용 조건을 확인하세요.

3. 판매 사이트·저장 상품 조회

식단 필요량은 유지합니다. 상품별 포장 총용량과 단위를 확인하고 비교 목록에 추가하거나 구매 개수를 선택하세요.

4. 판매상품·배송비 비교 목록

조회 상품의 ‘비교 목록에 추가’를 누르세요. 이 목록은 현재 화면에서만 유지되며 새로고침하면 지워집니다.

비교할 상품 추가

배송비가 확인된 상품만 배송비 포함 총지출을 계산합니다. 쿠폰·카드 적용가는 별도이며 무료배송은 이 상품의 구매금액 기준입니다. 상품의 종류·손질 상태·용량·판매가를 확인하세요. 판매처 이동은 구매 완료 기록이 아닙니다.
