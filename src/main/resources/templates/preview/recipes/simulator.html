식단에 쓸 요리

요리 더 고르기

추천에서 고른 요리 또는 저장한 MyRecipe를 사용합니다. 인분과 재료별 분량을 확인해 주세요.

영양 그래프 기준

녹색 기준: 성별·연령별 일반 참고량 · 파란 기준: 내가 입력한 개인 목표. 개인 목표 없이도 일반 참고 기준으로 그래프를 표시합니다.

초기 참고값은 남성 19~29세입니다. 회원 건강정보에서 자동으로 가져온 값이 아니므로 본인에 맞게 선택하세요. 19세 이상 일반 성인 참고용이며 열량은 집단의 필요추정량입니다. 실제 필요량은 체격·활동량 등에 따라 다릅니다. 소아·임신/수유·별도 식사 제한에는 개인 처방으로 적용하지 않습니다.

개인 하루 목표 입력 · 선택

입력 범위는 오입력 방지용이며 권장량이 아닙니다. 빈칸은 목표를 만들지 않습니다. 일반 성인 비율 참고를 선택하면 입력 열량에서 탄수화물·단백질·지방 범위를 계산하며 직접 입력한 g 목표가 우선합니다. 이 브라우저의 계정별 초안에 보관합니다. 주간·월간 추천 시 직접 입력한 목표량은 Gemini에 전송하며, 성별·연령대와 저장된 건강정보는 전송하지 않습니다.

MyPage 저장 식단 보기

선택한 날짜·끼니의 식단을 불러오거나 저장합니다. 저장하면 같은 날짜·끼니의 기존 시뮬레이터 계획이 교체됩니다.

현재 한 끼의 음식과 먹을 분량을 확인한 뒤 적용하세요. 적용은 선택한 끼니의 초안만 변경합니다. MyPage에 반영하려면 적용 후 해당 주에서 ‘이번 주 저장’을 눌러주세요.

함께 먹을 음식 추가

이미 한 끼를 구성했어도 더 추가할 수 있습니다. 입력한 음식명·현재 음식과 재료·선택한 추천 조건을 Gemini에 보내 후보를 받습니다. 후보 확인 후 직접 추가하세요.

영양 계산을 누르면 음식·재료명을 Gemini에 보내 부족한 영양값을 추정·저장합니다. AI 추정값은 별도로 표시합니다.

주간·월간 추천은 후보를 미리 담지 않아도 Gemini가 메인·밥·반찬을 제안합니다. 추천받기를 누르면 현재 선택한 식사 방향·제외 재료·직접 입력한 목표와 공용 레시피를 Gemini에 전송합니다. 저장된 건강정보·개인 레시피 수정 내용은 전송하지 않습니다. 식단 제안은 MyPage에 자동 저장되지 않습니다.

MAKE ROOM FOR YOUR WEEK

나의 주간 식단

Gemini가 공용 레시피를 참고하고 부족한 요리를 새로 제안해 기간 식단을 구성합니다. MyRecipe 불러오기는 필수가 아닙니다. 날짜의 끼니를 수정할 수 있으며 월간은 선택한 달 전체를 구성하고 주차별로 표시합니다.

추천 기준 설정

Gemini가 아래 조건을 참고해 메인·주식·반찬을 제안합니다. 일반 기준·식사 방향·개인 목표를 구분하며 의료진의 치료 식단을 대신하지 않습니다.

탄수화물 50~65% · 단백질 10~20% · 지방 15~30%. 열량 목표를 자동 확정하지 않습니다.

별도 제한이 있으면 자동 영양 기준은 적용하지 않고 메뉴 배치만 사용합니다. 질환명으로 안전성을 판정하지 않습니다.

표기된 재료명만 확인합니다. 소스·제품의 숨은 알레르기 성분은 별도 확인하세요. 추천받기를 누르면 제외 재료를 Gemini에 보내고, SmartNF가 반환된 레시피의 기재 재료·조리 순서를 다시 확인합니다. 제외 조건은 새로고침 후 다시 확인하세요.

구성할 끼니

추천받기를 누르면 이곳에 Gemini 진행 상태와 결과가 표시됩니다.

영양 자료를 준비하고 있습니다. 주간·월간 추천은 바로 시작할 수 있습니다.

직접 바꾼 끼니는 현재 초안에 적용됩니다. 새 추천이 모두 완료되면 Gemini 식단으로 교체합니다. 실패한 경우 기존 식단은 유지합니다. 질환별 맞춤 처방이 아닌 식단 계획 후보입니다.

한 달 전체 초안 중 현재 주만 표시합니다. 주차를 옮겨도 다른 주의 음식과 변경 내용은 유지됩니다.

이번 주 저장은 표시된 주만, 한 달 전체 저장은 월간 초안 전체를 저장합니다. 선택한 날짜·끼니의 시뮬레이터 계획은 교체하고 제외한 끼니는 기존 시뮬레이터 계획에서도 뺍니다. 헬스케어·외식 등 다른 계획은 유지합니다. 저장 시 부족한 영양값은 음식·재료명을 Gemini로 보내 보완할 수 있습니다.
