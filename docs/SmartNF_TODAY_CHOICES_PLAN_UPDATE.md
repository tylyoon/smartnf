# 오늘의 선택 → 장보기·외식 계획 통합 업데이트

2026-11-04. 직전 SmartNF_SAVED_GUIDE_RESET_UPDATE.zip(개선 기록 140절)이 적용된 프로젝트 기준입니다.

## 적용
1. 실행 중인 서버를 종료합니다.
2. ZIP 안의 src / frontend / docs를 프로젝트의 같은 위치로 병합합니다. 외부 상위 폴더는 없습니다.
3. `bash run_local.sh`로 시작하고 브라우저에서 Ctrl+F5를 누릅니다.
4. 생성한 personal-mypage.js를 포함하므로 사용자 환경에서 npm 빌드는 필요하지 않습니다. 기존 V12/V13 테이블을 그대로 사용하며 새 migration은 없습니다. 기존 SQL/Flyway 파일을 수정하지 않았습니다.
5. Java/API도 바뀌었으므로 브라우저 새로고침만 하지 말고 서버를 재시작해야 합니다.

## 사용자 확인 순서
1. 식재료·식품 영양정보에서 음식·식재료를 선택하고, 필요하면 참고 레시피 재료를 연결합니다.
2. 하단 **오늘의 선택에 저장**을 누릅니다. 아직 장보기/외식 날짜를 입력하지 않습니다. 선택 자체가 계정 자동 저장은 아닙니다. 로그인 및 기존 계획 저장 동의가 필요합니다.
3. MyPage 달력의 오늘 날짜에 **오늘의 선택**이 표시되는지 확인합니다. 이는 저장한 목록 건수이며 개별 재료 수와 다릅니다. 건강별 식품 선택 가이드의 선택도 같은 방식으로 저장되며 관리 구분은 유지됩니다.
4. 건강 식생활 관리 가이드에서 선택한 날을 조회하고 해당 목록을 선택합니다. **날짜·장보기·외식 정하기**에서 식품 일부 또는 전체와 계획 날짜를 지정해 이동합니다.
5. 계획 저장이 성공하면 옮긴 식품만 원래 목록에서 제거됩니다. 옮기지 않은 식품은 남습니다. 음식의 연결 재료·출처·버전·건강관리 구분도 함께 유지됩니다. 실제 섭취로 기록하지 않습니다.
6. 가이드의 **선택 목록 수정**에서 메모·장보기/외식·식당·시간·식품·참고 재료를 수정합니다. **장보기/외식 계획 추가**로 선택 날짜에 새 계획을 만들 수도 있습니다. 외식에서는 음식 자료를 기본으로 별도 검색합니다. 일반 자료도 검색 범위를 바꾸어 찾을 수 있습니다.
7. 장보기 영역의 체크는 이제 **제외할 항목 선택**입니다. **선택 항목 제외하기**의 최종 확인 후 MyPage의 같은 목록에 반영합니다. 준비 완료 체크가 아닙니다. 식품 전체 제외와 계획 전체 삭제도 확인 후 처리합니다. 조리 원문·영양값·다른 날짜 계획은 수정하지 않습니다.
8. 다른 날짜로 옮기기는 날짜 지정 기능을 사용합니다. 같은 날짜의 변경사항 저장은 해당 날짜의 목록을 수정합니다. 화면에 저장할 날짜를 표시합니다.
9. 저장 오류 시 같은 요청 다시 시도로 처리하고, 충돌하면 다시 조회합니다. 다른 탭의 변경을 강제로 덮어쓰지 않습니다.
10. 로그아웃·재로그인 후 오늘의 선택 및 계획 유지, MyPage와 가이드의 동일 내용, 실제 네이버 장소 검색을 확인하세요.

## 검증 범위
- JS 단위 테스트 41개와 frontend 데이터 테스트 17개 통과, MyPage React 빌드 및 변경 JS 문법 통과.
- 실제 FoodPlanService/Models/Catalog + Spring JDBC/H2/TransactionTemplate의 별도 검증 18개 확인: 오늘의 선택 건수, 일부 이동, 원문 재료·관리 코드 보존, 같은 날짜 이동, 요청 재시도 멱등성, 계정 분리, 충돌 거절, 대상 쓰기 후 원본 쓰기 실패 시 양쪽 롤백, 동의 철회 삭제. 회원 잠금 대역을 사용한 별도 서비스 검증이며 실제 Spring Security 인증 테스트와 구분합니다.
- 실제 템플릿·JS·정적 JSON과 가상 계정 API의 Chromium: 선택 저장→계획 일부 이동→외식 수정→음식 검색·추가→레시피 재료 변경→최종 제외→500 응답 후 같은 ID 재시도→삭제/다른 날 보존→새 외식 계획→권한 거절 시 편집 내용 제거→MyPage 오늘의 선택 달력 클릭까지 확인. 320/390/800/1440px에서 상세/편집 가로 넘침 및 JS 오류 없음.
- FoodPlanTests에 오늘의 선택·이동·롤백 회귀 테스트 3개 추가. 이 환경은 Java 17 런타임이며 프로젝트 Java 21 전체 Gradle/Spring Boot 테스트는 실행하지 못했습니다. 사용자 환경에서 `./gradlew.bat test`로 전체 확인하세요. 별도 JDBC 검증을 전체 Gradle/MySQL 검증으로 표현하지 않습니다.
- 실제 식당 원재료 보장·질환 적합성 판정·개인 영양 합계/처방·외부 LLM은 이번 범위에 없습니다.
