# 다이어트 명칭·현재 체중 입력·음식 추천 보완

2026-10-27

## 적용 내용

1. 감량 조건의 사용자 표시를 ‘체중 관리’에서 ‘다이어트’로 변경했다. 내부 weight 조건 키와 기존 확정 데이터 필드명은 유지한다. 유지·증량까지 다이어트로 바꾸지 않는다.
2. 기존 건강정보 화면에서 기본정보 쪽의 ‘체중(kg)’ 입력을 ‘현재 체중(kg)’으로 표시하고 목표 체중 옆으로 이동한다. 실제 템플릿에 입력이 없으면 weight 필드 하나를 추가한다. 동일한 입력을 두 개 만들거나 비교평가용 값을 따로 저장하지 않는다.
3. 현재 체중·목표 체중·목표 기간을 기존 건강정보 확정과 복원에 연결한다. 입력 배치 변경만으로 기존 확정값을 지우지 않는다. 건강정보를 수정한 뒤 확정하지 않으면 기존 확정본이 유지된다.
4. 현재·목표 체중과 감량/유지/증량 방향이 서로 맞지 않으면 확정 전에 안내한다. 미입력 항목을 추정하거나 모두 필수로 바꾸지 않는다.
5. 건강별 식품 선택 가이드의 기본 화면을 ‘음식 추천’으로 명확히 표시한다. 요리명·조건별 추천 이유·재료·조리법을 확인한 뒤 ‘이 음식 선택’을 누를 수 있다. 식재료는 ‘식재료 참고’ 탭으로 구분한다.
6. 나의 관리항목에 다이어트(감량), 현재→목표 체중, 기간을 함께 표시한다. 미입력 값은 미입력으로 표시한다.

## 음식 추천 범위

- 전체 후보215개 중 음식110개(표준음식5·추천 재료 활용 레시피105), 식재료105개를 유지한다.
- 다이어트 단독 조건은 음식51·식재료27개가 연결된다. 다른 질환·알레르기·선택해제 조건에 따라 실제 화면 수는 줄어들 수 있다.
- 현재 체중·목표 체중의 차이로 개인 열량이나 식사량을 계산한 결과는 아니다. 현재 정책대로 확인된 질환·감량 조건·알레르기와 기존 범위 검사를 반영한다.
- 레시피 후보는 연결 재료의 근거를 활용하며 완성 요리 전체가 질환별 치료식으로 검증됐다는 의미가 아니다. 영양 기준량이 확인되지 않은 레시피에 원재료 영양값을 임의로 옮기지 않는다.
- 월간 식단·개인 섭취량 최적화는 헬스케어 완료 및 로그인·회원가입 이후 AI 식단 단계로 유지한다.

## 적용 순서

압축파일을 기존 smartnf 프로젝트 폴더에 병합한 뒤 Git Bash에서 실행한다.

```bash
python python/food_nutrition/install_allergy_bridge.py
```

이 도구는 기존 건강정보 템플릿 본문을 교체하지 않고 공통 스크립트·스타일 연결과 캐시 버전을 확인한다. 최초 백업을 유지하며 반복 실행해도 중복 삽입하지 않는다. 건강정보 템플릿은 사용자 PC에 있으므로 이 연결 갱신이 필요하다.

이후 서버를 Ctrl+C로 종료하고 다시 실행한다.

```bash
bash run_local.sh
```

브라우저에서 Ctrl+F5를 누른다.

## 확인 방법

1. 건강정보 → 나의 상태 → 체중 목표 영역에서 현재 체중과 목표 체중이 함께 보이는지 확인한다.
2. 정확히 아는 현재 체중·목표 체중·목표 기간·방향을 입력하고 ‘나의 건강정보 확정’을 누른다. 단순 표시 확인은 기존 가상 예시로도 가능하며 실제 질환을 임의로 입력할 필요는 없다.
3. 새로고침 후 현재·목표 체중과 기간이 복원되는지 확인한다.
4. 건강별 식품 선택 가이드 → 나의 관리항목에서 확정한 체중과 기간을 확인한다.
5. 감량 조건이면 ‘다이어트’로 표시되는지, 음식 추천 탭이 기본 선택인지 확인한다.
6. 음식 카드의 추천 이유·재료와 조리법을 확인한 뒤 ‘이 음식 선택’을 누른다. 아래 나의 선택 식품에 음식이 추가되고 다시 누르면 해제되는지 확인한다.
7. 건강 식생활 관리 가이드에서 선택 음식의 장보기·조리·외식 연결을 확인한다.

## 검증

- 기존 현재 체중 컨트롤 이동 / 없을 때 생성 / 필드 하나 유지 / 같은 weight 값으로 BMI 참조 검사 통과.
- 현재·목표·기간 확정 및 새로고침 복원 검사 통과. 목표 방향 모순 시 기존 확정본 보존 검사 통과.
- 미입력 진행 허용, 다이어트 표시, 음식 기본 표시·선택 검사 통과.
- 추천 엔진·조건별 근거·기존 선택/해제/확정 분리·알레르기·17영양항목·식생활 안내 회귀검사 통과.
- 화면폭320·390·1440에서 가로 넘침·JavaScript 오류 없음. 모바일 추천 화면 확인.
- 연결 업데이트 도구6개 Python 검사 통과(내보내기 검사 포함).
- 실제 사용자 건강정보 템플릿 적용과 Spring Boot/MySQL 실행은 사용자 PC에서 최종 확인한다.

## 변경 파일과 후속

- health-profile.js: 현재 체중 입력 준비·동일 필드 유지·확정본 비교·방향 검증.
- food-choice.js / recommendations.html: 다이어트 요약·음식 기본 추천·선택 버튼과 표시.
- selection_rules_v1.json / recommendation-guide-v1.json: 다이어트 표기와 추천 버전 갱신.
- food-allergy.css / install_allergy_bridge.py: 기존 화면에 적용하는 스타일과 연결 갱신.
- 다른 페이지·로그인/회원가입·DB·MyPage 기능을 이번 작업에서 확장하지 않았다. 기존 전체 SmartNF 개발 후 헬스케어 추출 원칙 유지.
