# 건강정보 비교평가 시각화 보완

사용자가 제공한 최신 info.html 및 static(4).zip 기준입니다.

## 적용
ZIP 안의 src·docs를 SmartNF 프로젝트 루트에 병합합니다. 서버를 재시작하고 Ctrl+F5로 새로 불러옵니다. 별도 Python 명령은 필요 없습니다.

## 확인
1. 건강정보에서 비교평가 탭을 선택합니다.
2. 가상 예시 보기에서 BMI·혈압·혈당·혈중지질의 내 수치 마커와 참고선을 확인합니다.
3. 나의 상태 입력 후 내 입력 결과 보기로 전환하여 수치가 반영되는지 확인합니다.
4. 미입력·측정/검사 조건 부족은 평가 전/확인 필요로 유지되는지 확인합니다.
5. 수치가 표시 축을 벗어나면 실제 수치와 축 밖 안내가 함께 나오는지 확인합니다.
6. 상단 공통 메뉴 한 개만 보이고 내부 나의 상태·비교평가·맞춤 관리 항목 탭은 유지되는지 확인합니다.
7. 모바일에서도 카드와 수치·설명이 가로로 넘치지 않는지 확인합니다.

## 변경 범위
기존 수치·참고 기준·판정 로직·입력 조건·출처를 유지한 표시 개선입니다. 또래 순위·개인 치료 목표·효과 예측·장기 기록을 생성하지 않습니다. 기존 기준의 최신성 검토 및 서버 평가 검증은 후속 작업입니다.

BMI·혈압·공복혈당·당화혈색소·지질은 기존 코드의 참고선만 표시합니다. 식후 혈당과 추가 검사는 기존대로 검사별 확인이 필요합니다. 구간의 바탕색은 숫자 구간 구분이며 건강 등급·위험 정도를 뜻하지 않습니다. 판정은 별도 문구로 확인하세요.

## 검사
원본/수정본 판정 동일성 및 실제 HTML의 320/390/1440px 폭 검사. 실제 로컬 Spring 서버의 최종 확인은 적용 후 진행합니다.
