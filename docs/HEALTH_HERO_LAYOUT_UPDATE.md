# 헬스케어 서브메인 히어로와 비교평가 배치

## 적용
ZIP의 src·docs를 SmartNF 프로젝트 루트에 병합합니다. 서버 재시작 후 Ctrl+F5로 확인하세요. Python 명령·데이터 재수집은 필요 없습니다. 이전 NHIS 레이더 업데이트가 적용된 프로젝트를 기준으로 합니다.

## 확인
- `/preview/health`: 기존 제목·설명을 합친 낮은 히어로, 장식 그래픽. 서비스 카드4개와 이동 링크 유지.
- `/preview/health/info` → 비교평가: 공통 제목 중앙, 오른쪽 별도 제목 숨김, 차트·표 박스 상하 일치.
- 안내 문구는 좌우 박스 아래 공통으로 표시. 표 caption은 화면에서는 숨기고 보조기기 접근성을 위해 유지.
- 모바일: 히어로 문구 중심, 차트→표 순서. PC와 같은 고정 높이를 강요하지 않음.

## 범위
서브메인 HTML은 기존4카드 화면 기준으로 소개 영역과 히어로 CSS 연결만 수정했습니다. 건강정보 HTML은 새 CSS/레이더 스크립트 캐시 참조만 갱신합니다. 수치·평균 데이터·사용자 조건·평가·선택·저장 규칙은 변경하지 않았습니다.

## 검증
320/390/900/1440폭, PC좌우상단·하단 오차1px미만, 모바일세로순서, 히어로1개·서비스카드4개 유지, 기존 평균·연령매칭·혈압집단·미입력 동작 검사. 실제 Spring 서버에서의 확인은 적용 후 진행합니다.
