# 저장 계획 전용 가이드·페이지 초기화 업데이트

2026-11-04. 직전 SmartNF_LIVING_PLAN_GUIDE_UPDATE.zip(개선 기록 139절)이 적용된 프로젝트에 병합하세요.

1. 서버를 종료하고 ZIP 안의 src/docs를 프로젝트의 같은 경로에 덮어씁니다.
2. `bash run_local.sh` 실행 후 Ctrl+F5를 누릅니다. DB migration/npm 설치는 없습니다.
3. 식품을 선택하고 저장하지 않은 채 다른 페이지로 이동하세요. 브라우저 기본 이탈 확인에서 취소하면 선택이 유지되고, 이동하면 초기화됩니다. 브라우저 정책상 사용자 동작이 없거나 모바일 종료 등에는 확인창이 생략될 수 있습니다.
4. 다시 선택 페이지로 오거나 뒤로가기를 하면 이전 선택·검색 화면이 복원되지 않아야 합니다. MyPage에 이미 저장된 계획과 확정한 건강정보·관리항목은 유지됩니다.
5. 식품을 MyPage에 저장한 뒤 건강 식생활 관리 가이드에서 날짜를 조회하세요. 현재 임시 선택 탭 없이 저장 계획만 표시됩니다.
6. 외식하기→외식 장소 찾기를 펼치면 지역 입력/장소 종류/검색어와 버튼이 정렬됩니다. 모바일은 세로 배치입니다. 실제 검색에는 기존 네이버 설정이 필요합니다.

검증: 기존 Node 24개 및 생명주기 2개 통과. 실제 정적 자원과 가상 API의 Chromium 검증(4개 화면 폭·저장 내용 보존·동의 철회/권한 거절·저장 전용/장소 입력 정렬) 통과. 실제 Spring/MySQL 저장 및 지도 제공자 호출은 사용자 환경에서 확인하세요.
