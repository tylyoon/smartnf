# 266. 대표1kg 옵션 확인·재료별 선택상품 구매금액 (2026-11-17)

승인된 화면·저장 흐름 개선입니다. 1kg/2kg 혼합 옵션 상품은 대표 규격1kg으로 표시하되 검색 대표가격을1kg가격으로확정하지않습니다. 이번인식범위는 라이브조회 k:영수증상품의 1kg/2kg(대소문자·공백·전각슬래시포함)입니다. 모든옵션형상품을자동인식하는기능은아닙니다.

- 포장총량1000g은대표값으로표시하고읽기전용으로둡니다. 판매처에서확인한옵션명과해당1kg가격은별도입력하며가격은빈칸으로시작합니다. 확인체크전단가/구매금액계산과비교·저장을보류합니다. 옵션명/가격수정시체크를해제합니다.
- 기존일반상품도필수포장량/구매개수/확인체크가충족되어야선택저장버튼이활성화됩니다. 이미규격이확인된일반상품의비교추가는기존동작을유지합니다.
- Save요청에optionName/optionPriceConfirmed를추가합니다. 서버가회원별15분조회영수증을검증하고실제원상품이1kg/2kg혼합옵션인경우에만사용자확인가격을허용합니다. 대표규격은g/1000만허용하며옵션명·가격범위검사및원상품명/판매처/URL/조회시각검증은유지합니다. 일반상품의임의가격변경은거부합니다.
- 옵션이름·사용자확인가격·검색원가격을기존source_details에구분저장합니다. DB컬럼/마이그레이션추가는없습니다. 사용자입력확인금액이며자동검증실판매가/실제결제내역으로표시하지않습니다.
- 장보기각재료의예상비용아래에선택상품구매금액·포장량×구매개수·판매처·상품명·옵션근거를표시합니다. 구매금액미선택/조회실패/목록변경전선택을구분합니다. 배송비별도/실제결제금액아님을표시합니다.
- 기존필요량예상합계와선택상품구매합계는별개로유지합니다.예상금액에구매합계를다시더하지않습니다.

변경영역:product-offers.js,shopping-budget.js,관련모듈/템플릿캐시버전,ingredient-purchase.css,shopping-lists.css,ShoppingProductService.java,KakaoProductSnapshots.java,관련Node/Java검사.
