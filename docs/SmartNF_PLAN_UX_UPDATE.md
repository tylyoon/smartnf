# SmartNF 계획 화면 개선 적용

기존 장보기·외식 계정 저장(V12 적용 완료) 프로젝트용 변경 파일입니다.

1. 실행 중인 서버를 종료합니다.
2. ZIP의 src/frontend/docs를 SmartNF 프로젝트 루트에 덮어씁니다. 바깥 폴더는 없습니다.
3. `bash run_local.sh`로 재실행하고 브라우저에서 Ctrl+F5를 누릅니다.

DB 변경·npm 설치·가상자료 재생성은 없습니다. 기존 식당명/시간도 유지됩니다.

검색 완료 표시, 장보기/외식 독립 날짜 탭, 별도 저장 버튼 행, 입력 오류/실제 저장 재시도 구분, 미저장 편집에만 이탈 경고, MyPage 조회 정렬을 반영했습니다.
식당명·방문 시간은 건강 식생활 관리 가이드 → 외식 방문 계획에서 수정합니다. 먼저 영양정보에서 외식 계획을 MyPage에 저장하세요.

검증: React 빌드, Node21건, 실제 Spring/H2+Chromium 저장/가이드/MyPage 복원·1440/390px 정렬 확인. 상세 변경/보안 조건은 SmartNF_IMPROVEMENTS.md 130절을 참조하세요.
