## 적용하고 확인하기
1. ZIP 안의 파일을 기존 smartnf 프로젝트 루트에 **병합**합니다. 이번 ZIP에는 보완된 화면용 영양 데이터와 manifest.json도 포함됩니다. 기존 데이터 폴더 전체를 삭제할 필요가 없습니다.
2. 서버를 종료 후 `bash run_local.sh`로 실행하고 브라우저에서 Ctrl+F5를 누릅니다.
3. `http://localhost:8080/preview/health/foods`에서 소고기 등 식재료를 열어 인 항목을 확인합니다. 음식에는 공란인 항목도 있습니다.
4. `http://localhost:8080/preview/health/recommendations`에서는 추천 중단 안내가 유지됩니다.
5. 상세 결과는 `docs/recommendation-group-review-20261026/GROUP_REVIEW.md`, `docs/recommendation-review-phosphorus-20261026/REVIEW_REPORT.md`, `docs/phosphorus-export-review-20261026/validation.json`을 확인합니다.

## 다시 생성할 때만 실행
이미 보완된 화면용 데이터를 동봉했으므로 지금은 재수집·재생성이 필요 없습니다.
원본을 갱신할 때는 프로젝트 루트에서:

```bash
python -m pip install -r python/food_nutrition/requirements_inspection.txt
python python/food_nutrition/inspect_food_db.py
python python/food_nutrition/export_food_browser.py --nutrition-run 검사결과폴더명
```

기본 원본 위치는 python/food_nutrition/data/raw/dishes/20260828_음식DB_19617건.xlsx 및 raw/ingredients/식품성분표(10개정판).xlsx입니다. 원본 경로가 다르면 inspect 명령의 --dishes/--ingredients 인자로 지정합니다.
