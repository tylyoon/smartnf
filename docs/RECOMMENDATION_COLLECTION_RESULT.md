## 확인된 공백·충돌

1. 당뇨 식품교환표 최신 지침은 유료 출판물. 공개 판매 안내/목차만 확인,본문 표 미확보. 구매와 프로그램 재사용 권한은 별개이므로 공개 대체자료 또는 정식 이용 범위를 확인해야 한다.
2. 병원 페이지의 추천 식단은 일부 이미지. 이미지속 모든 음식/중량을 확보한 것으로 처리하지 않음. 통풍의 퓨린 표도 텍스트 본문에 수치가 없어 미확보.
3. 신장과 일반 심혈관 식사자료는 식품 선택 방향이 충돌할 수 있음. 병기·투석·칼륨/인 검사·개별 처방 없이 교집합 추천을 만들지 않는다.
4. 식품군의 권장과 특정 제품/조리후 인분 적합성은 별개. source→term→food_code→상태/단위/분량→제외조건 검토가 필요.
5. 병원 페이지의 재사용 조건은 별도 검토 상태. 접근 가능/내용 확인을 서비스 재배포·임상 승인으로 처리하지 않음. 공개 API는 이번 검토한 병원 페이지에서 확인하지 못했으며 존재하지 않는다고 단정하지 않음.
6. 대한신장학회는 구체 식사 지침의 정확한 공개 문서를 아직 특정하지 못해 미확보로 기록. 공지목록을 식이 근거로 대체하지 않음.
