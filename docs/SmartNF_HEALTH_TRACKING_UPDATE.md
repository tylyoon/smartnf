# MyPage 관리항목·실천 기록 통합

MyPage의 **나의 관리항목·실천 기록**에서 관리할 항목 선택, 날짜별 입력·수정, 월별 변화를 이용합니다. 이전 실천 기록 주소로 접속해도 통합 화면을 엽니다.

| 기록 방식 | 항목 |
| --- | --- |
| 수치 | 걸음 수(보), 걷기 시간(분), 체중, 혈압, 공복혈당, 허리둘레, 수면 시간 |
| 실천 여부 | 균형 잡힌 식사, 규칙적인 식사, 짜게 먹는 습관 줄이기, 단 음료·첨가당 줄이기, 포화지방 줄이기, 야식 줄이기, 금연, 음주 줄이기 |

1. 상단에서 관리할 항목을 체크하고 **선택 항목 저장**을 누릅니다.
2. 월간 달력에서 날짜를 선택하고 값을 입력한 뒤 **일일 기록 저장** 또는 **수정 내용 저장**을 누릅니다.
3. 아래 **월별 변화**에서 수치 그래프와 실천 상태를 확인합니다. 0과 미기록을 구분하며, 미기록 구간에서 그래프 선을 끊습니다.
4. 예전 날짜의 메모와 실천 상태는 **이전 실천·측정 기록 원문 확인**에서도 볼 수 있습니다. 선택을 해제한 항목의 기존 기록은 보관됩니다.

기존 헬스케어에서 확정한 관리 방향은 별도로 유지합니다. 선택 설정을 처음 열면 체중·혈압과 해당하는 확정 관리항목을 기본값으로 보여줍니다. 걷기 관리항목은 걸음 수·걷기 시간으로 연결합니다. 이전에 저장한 걷기 실천 여부는 원문에서 확인할 수 있습니다.

## 적용 순서

1. 실행 중인 SmartNF를 종료합니다.
2. 최신 SmartNF 프로젝트 루트에 ZIP을 풀고 같은 경로의 파일을 덮어씁니다.
3. `bash run_local.sh`로 다시 시작한 뒤 브라우저에서 `Ctrl+F5`를 누릅니다.

서버 시작 시 Flyway V13이 일일 기록 테이블에 선택형 지표 열을 추가하고 회원별 선택 테이블을 생성합니다. V12까지 적용된 환경을 기준으로 합니다. 기존 기록과 메모는 그대로 읽습니다. 이미 빌드된 브라우저 파일을 포함합니다.

## 검증 범위

H2와 실제 JDBC 서비스로 회원별 데이터 분리, 유효 범위 검사, 재시도, 선택 해제 후 보관, 이전 요청 호환성, 저장 동의 철회 후 삭제를 확인했습니다. Chromium에서 빌드된 MyPage와 대역 API를 연결해 메뉴, 기록 저장·조회, 미저장 날짜 이동 보호와 화면 폭 5개를 검증했습니다. 사용자 로컬 MySQL과 전체 Gradle 테스트는 이 환경에서 실행하지 못했습니다.
