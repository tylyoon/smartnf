# 국민건강보험공단 평균 비교 레이더 연결

## 적용과 확인
1. ZIP의 src·python·docs를 SmartNF 프로젝트 루트에 병합합니다. 정리 데이터가 포함되어 있어 재수집·Python 실행은 필요 없습니다.
2. 기존 방식으로 서버를 재시작하고 Ctrl+F5를 누릅니다.
3. 건강정보 → 비교평가 → 가상 예시 보기에서 회색 평균100과 초록 사용자 상대값을 확인합니다. 초기 예시는45세 남성입니다.
4. 내 입력 결과 보기에서 나이·성별·필요한 측정값·측정일/검사일·검사 조건이 충족된 지표가 표시되는지 확인합니다. 알 수 없는 값은 비워둡니다. 미입력·조건 미확인은0점이나 평균으로 채우지 않습니다.
5. 혈압 평균 비교 집단을 복용자 포함/제외로 바꿔 확인합니다. 이는 참조 집단 선택이며 사용자의 약 복용 여부를 판단하거나 변경하지 않습니다.
6. 모바일에서는 차트 아래에 표가 배치됩니다. 평균의 출처·연령구간·수검연도·비교 집단을 펼쳐 원본 위치를 확인합니다.

## 실제 평균 데이터
- 사용자 nhis.zip 원본10개, 데이터13408행을 정리. 전국 평균540행을 표시용 JSON에 연결. 실제로540개 전국 행 모두의 평균·성별·연령표시·원본행을 원본 셀과 독립 대조.
- 현재 차트8축: BMI/수축기/이완기/공복혈당/총콜레스테롤/LDL/HDL/중성지방.
- 전국·성별·원본 연령구간을 정확히 매칭.20~24세,25~26세 등 원본 구간 유지,75세 이상은 원본 개방 구간.19세 이하/성별 미확인 비교 없음. 연령을 임의 보간하지 않음.
- HDL/LDL은 원본에 전국 포함11지역만 있어 타 지역을 만들어내지 않음. 허리둘레는 원본에 전국 행이 없어 전국 평균을 임의 합산하지 않음.
- 혈압: 수축기/이완기와 고혈압약 복용자 포함/제외를 각각 보존, 기본 포함 집단. 원본의 집단을 합치거나 사용자 복약정보로 추정 선택하지 않음.
- 혈색소·크레아티닌은 원본 및 전체 정리 데이터에 포함/제외 집단을 보존했으나 현재 레이더 범위에 추가하지 않음.
- 당화혈색소·일반 식후혈당 대응 평균은 미확보. 공복혈당 또는 혈색소 평균으로 대체하지 않음.

## 표시 방법
평균은100, 사용자 표시값은 사용자 원수치÷해당 집단 평균×100입니다. BMI는 원래 키/체중으로 계산한 반올림 전 값을 사용합니다. 실제값·평균은 별도 표에 최대 소수2자리로 표시합니다. 차트는 건강점수·백분위·진단 기준·개인 치료 목표가 아닙니다. HDL도 역수/점수로 바꾸지 않으며 지표 방향을 동일한 좋음/나쁨으로 해석하지 않습니다.

회색 점선은 참조 평균이 있는 축에만, 초록점은 유효 입력·기존 비교 조건이 확인된 축에만 표시합니다. 누락 축을 가로질러 연결하지 않고8개 모두 표시될 때만 사용자 영역을 채웁니다. 데이터가 일부여도 상세 평가와 표를 이용할 수 있습니다. 자료 읽기 실패 시 기존 상세 평가를 유지하며 재시도 버튼을 제공합니다. 사용자 건강정보를 외부 API로 보내지 않습니다.

## 수검연도와 이용조건
평균자료는 과거 건강검진 수검자 참조표준이며2026년 현재 국민 평균으로 표시하지 않습니다. 비만지수2015–2016·허리둘레2013–2014는 사용자 제공 공식 화면, 혈압2017–2019·총콜레스테롤2016–2017은 공식 제공 설명으로 확인했습니다. 나머지는 원본 파일 내 수검연도가 없어 미확인 상태를 표시합니다. 파일/기관 공표연도를 조사연도로 간주하지 않습니다. 각 파일/집단의 원문 포함·제외 조건 추가 확인을 후속으로 유지합니다.

국민건강보험공단 한국인 건강지수 참조표준, 공공누리 제2유형(출처표시·상업적 이용금지). 개인 학습·제출 범위를 기준으로 제공하며 향후 상업 서비스 적용 시 이용 범위를 별도 확인합니다. 출처 평균과 원수치를 보존하고 표시용 비율은 계산값으로 구분합니다.

## 프로젝트 경로
- 원본: python/health_collection/data/raw/peer_statistics/nhis/
- 전체 정리 데이터: python/health_collection/data/processed/peer_statistics/nhis-20261027/normalized_all.json
- 표시 데이터: src/main/resources/static/js/data/nhis-peer-reference-v1.json
- 재생성 도구: python/health_collection/build_peer_reference.py (openpyxl 필요, 기존 식품 분석 환경 사용)
- 파일별 행수·원본SHA256: inspection.json

재생성이 필요할 때만 프로젝트 루트에서 실행합니다.

```bash
python python/health_collection/build_peer_reference.py
```

도구는 원본을 변경하지 않고 정리/표시 파일만 갱신합니다. 현재10개 원본 형식과 정확한 파일명을 검사합니다. 다른 버전·파일 구성이면 중단하며 임의로 혼합하지 않습니다. 수치0/음수·비정상 연령·중복집단·연령구간 누락/중첩·전국 집단 부족은 중단합니다. 네트워크·인증키·DB 사용 없음.

## 기술/역할
Python: 원본10개 전수 정리·집단/단위/연령 검증·불확도와 표준편차 구분 보존·공개 JSON 출력. Frontend: SVG 레이더·동일 결과의 실제값 표·자료 로드 실패/재시도·반응형. Backend/MyPage 회원 저장은 이번 범위에 추가하지 않음. 기존 상세 판정 기준과 사용자 입력/알레르기/선택 규칙 유지.

## 검증
540개 표시 평균 원본 셀 독립 대조. 기존 판정과 동일성.8개축과 계산식, 서로 다른 혈압집단,19/20/24/25/26/27/74/75세 경계와75세 이상, 부분 입력·결측·소아·320/390/900/1440폭, 로드 실패→재시도 확인. 실제 로컬 Spring 서버에서의 최종 확인은 적용 후 진행합니다.

## 후속
원본별 수검연도/포함제외조건 보완, 국가 기준 최신성 및 기존 BMI 근거링크 교정 검토, MyPage 재사용·Backend 참조자료 버전 관리. 이 비교가 치료 적합성 검증 완료를 뜻하지 않음.
