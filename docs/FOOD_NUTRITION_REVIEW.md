## 공식 설명 확인

‘DB 설명’ 시트는 텍스트 셀이 아니라 이미지로 설명문이 포함되어 있어 직접 확인했다.

- 기준: 가식부 100g. `-`는 미측정 결측, 괄호 수치는 인용 또는 재료량 환산, `Tr`는 검출되었으나 정량 가능한 최소 농도 이하인 미량.
- 원래 표기와 상태를 함께 저장한다. 괄호 숫자는 값과 quoted_or_calculated 상태를 함께 보존하며 직접 분석값으로 단정하지 않는다.
- Tr/tr/(Tr)는 정량값 없이 trace 상태로 보관한다. 0으로 대입하지 않는다. 표시 범위·정량한계 수치는 추정하지 않는다.
- 같은 셀에 숫자가 있어도 출처별 생성 방법을 별도로 보존한다. numeric은 일반 숫자 표기라는 뜻이며 모두 직접 분석값이라는 뜻이 아니다.
- 출처 표기 예: 농촌진흥청. 2026. 국가표준식품성분 DB 10.4. https://koreanfood.rda.go.kr
- 식품성분 DB Excel의 출처표시 조건과 책자 PDF의 이용조건을 구분한다. 다른 제공처 파일의 이용조건은 별도 유지한다.

## 연결 기준

1. 원본: 파일명·SHA256·시트·Excel 행·버전·출처를 보존한다.
2. 식별: 제공처+버전+식품코드로 식별한다. 이름·단위가 같다고 동일 식품으로 통합하지 않는다.
3. 국가표준 코드: 10.4 본표의 색인과 부록2의 색인을 연결하고 식품명 일치를 검증한다. 일치하지 않으면 중단한다.
4. 단위: 성분별 g/mg/μg와 기준량을 분리한다. mg↔g 계산은 차후 명시적 환산으로 수행한다. 밀도 없이 100mL↔100g 환산 금지.
5. 음식↔식자재: 구성 재료·중량·조리 방법·완성량 근거가 필요하다. 이번 두 DB를 음식명으로 직접 연결하지 않는다.
6. 건강 가이드: 관련 영양소 탐색 후보만 기록한다. 건강 평가기준·개인 목표·복수질환 제외/주의 조건 검토는 별도이며 이번 검사에서 승인하지 않는다.
