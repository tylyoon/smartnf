# 계획 저장 후 오늘의 선택 날짜 유지 (2026-11-05)

- 원인: 저장 성공 후 W.openDate(target)로 목적 날짜를 자동 조회하여 상단 오늘의 선택 날짜까지 변경됐다.
- 변경: 성공 후 원래 조회 날짜(source)를 다시 불러와 남은 음식을 표시한다. 목적 날짜는 완료 메시지 「YYYY-MM-DD 계획으로 MyPage에 저장했습니다」에만 표시한다. MyPage 계획은 입력한 목적 날짜에 저장하며 이동 API/저장 데이터는 변경하지 않는다.
- 검증: 실제 JS Chromium+대역 API에서11/05 목록→11/07 외식 계획 저장 후 상단11/05 유지, 완료문구11/07, 원래 미선택 음식 잔여와 목적 날짜 계획 보존 확인. 기존 음식 카드/응답 유실 동일요청 재시도·중복없음/잠금/5폭·JS오류없음 회귀 통과. 실제 사용자 MySQL 검증과 구분.
- 적용:156절 적용 프로젝트 서버 종료→ZIP src/docs 병합→bash run_local.sh→Ctrl+F5. DB 초기화/마이그레이션 없음.
