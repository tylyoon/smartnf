# 헬스케어 공통 화면 정리 — 경로 표시 보완

## 적용
1. ZIP의 `src`, `python`, `docs`를 SmartNF 프로젝트 루트에 병합합니다.
2. 프로젝트 루트 Git Bash에서 실행합니다.

```bash
python python/food_nutrition/install_healthcare_ui.py
```

3. 기존 서버를 Ctrl+C로 종료하고 `bash run_local.sh`로 다시 실행합니다.
4. 브라우저에서 Ctrl+F5 후 확인합니다.

이 패치는 4개 HTML 본문을 교체하지 않습니다. 설치 도구가 공통 CSS/JS 참조를 추가하고 최초 원본을 `.before_healthcare_ui.bak`으로 보관합니다. 반복 실행 시 중복 추가하지 않습니다. DB·환경설정·인증키 변경은 없습니다.

## 화면 구성
- 공통 서비스 메뉴: 건강정보 / 식재료·식품 영양정보 / 건강별 식품 선택 가이드 / 건강 식생활 관리 가이드. 현재 페이지 강조. 필수 순서를 강요하는 단계 번호는 사용하지 않습니다.
- 현재 상태: 건강정보 확정 여부, 관리항목 수, 임시 선택 수, 추가 확정 수를 기존 읽기 API가 제공하는 범위에서 표시. 원래 건강정보 화면에 식품 API가 없으면 해당 수치를 임의 생성하지 않습니다.
- 소개 영역 축소: 영양정보·추천·식생활 가이드의 소개 높이를 줄여 본문 접근 개선. 기존 건강정보 본문 배치 유지.
- 페이지 바로가기: 현재 표시된 주요 제목으로 이동. 키보드 초점 이동 및 동적 탭 내용 반영.
- 모바일: 공통 메뉴 2열, 영양 검색/상세 1열, 버튼 간격·초점 표시·선택 테두리 개선.
- 출처·기준량·주의사항 및 기존 추천 규칙 유지. 현재 선택과 확정 등록을 별개로 표현.

## 확인 방법
| 확인할 위치 | 기대 결과 |
|---|---|
| `/preview/health/info` | 기존 입력·비교평가·관리항목을 유지하면서 공통 메뉴와 확정 상태 표시 |
| `/preview/health/foods` | 현재 메뉴 강조, 소개 축소, 검색·상세 확인·선택 가능 |
| `/preview/health/recommendations` | 기존 관리조건·추천·근거·선택 유지 |
| `/preview/health/diet` | 장보기/조리/외식 탭·지도 및 크게 보기 유지 |
| 식품 선택/해제 | 임시 선택 수가 즉시 증가/감소 |
| 선택 식품 추가 확정 | 추가 확정 수 별도 반영, 계정 미저장 안내 |
| 본문 바로가기 버튼 | 해당 제목 이동 및 키보드 초점 표시 |
| 모바일 320/390px | 메뉴 2열·본문 가로 넘침 없음 |

## 후속 개선 범위
이번은 공통 구조와 상태 시각화 1차입니다. 건강 수치별 기준 범위 그래프와 영양성분 비교 시각화는 실제 화면·기준 데이터와 연결해 후속 적용합니다. 임의 건강점수나 또래 백분위를 만들지 않습니다. 원본 건강정보 전체 화면은 로컬 적용 확인이 필요합니다.

## 기술과 남은 작업
| 구분 | 현재·이번 적용 | 남은 작업 |
|---|---|---|
| Frontend | Thymeleaf 원본 + 공통 CSS/JS, 반응형·접근성·이벤트 상태 표시 | 실사용 확인 후 페이지별 시각화 |
| Backend/DB | 기존 읽기 구조 유지, 브라우저 임시 상태와 확정 구분 | 회원별 저장·평가 API·MyPage 연계 |
| Python | 기존 HTML 본문을 보존하는 반복 설치 도구 | 정보 갱신 자동화·자료 품질 확인 지속 |
| AI/LLMOps | 이번 화면 정리에서 신규 적용 없음 | 근거 연결 상담·생성 결과 검증 |
| DevOps/MLOps | 실제 서비스 배포·모델 운영 완료를 의미하지 않음 | CI/CD·운영 감시·필요 모델 평가 |

계획/실제 섭취·장기 변화·목표달성도는 MyPage 작업 목록으로 유지합니다. 다른 서비스 페이지는 변경하지 않습니다.


## 경로 표시 보완 (ui2)
모든 화면에서 경로 표시를 공통 메뉴 위로 통일합니다. 건강정보는 `홈 / 헬스케어 / 건강관리`, 다른 세 화면은 마지막 항목에 해당 페이지 정식 이름을 표시합니다. 기존 서로 다른 경로 표시 중복을 제거합니다. 이미 1차를 적용했어도 같은 설치 명령을 다시 실행한 뒤 서버 재시작·Ctrl+F5로 확인하세요.


## 중복 서비스 메뉴 제거 (ui3)
건강정보 소개 아래 기존 네 서비스 메뉴가 다시 나오는 문제를 수정했습니다. 상단 공통 메뉴는 유지합니다. 내부 나의 상태·비교평가·맞춤 관리 항목 메뉴는 보존합니다. 같은 설치 명령을 다시 실행하고 서버 재시작 후 Ctrl+F5로 확인하세요.
