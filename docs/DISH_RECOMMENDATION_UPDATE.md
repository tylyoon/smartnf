이는 원문의 식품 선택 방향과 연결한 **일반 음식 선택 참고**입니다. 임상적으로 개인 적합성이 승인된 치료식, 완성 식단, 개인 권장량이나 예측 건강 결과가 아닙니다. 체중 관리에서 통곡물 밥의 조리 형태를 연결한 부분은 SmartNF의 범위 제한된 해석이며, 원문 기관이 해당 식품코드를 직접 승인했다는 뜻이 아닙니다.

## 사용 방법
- 음식 카드의 ‘추천 이유·출처 확인’: 조건별 근거 문서와 관련 절을 확인합니다.
- 영양표: 식약처 음식 DB의 **조리된 음식 100g 기준**입니다. 실제 1인분/1공기나 아래 참고 레시피의 영양값이 아닙니다.
- ‘나의 선택에 담기’: 아래 ‘선택한 음식’에 표시합니다. 다시 누르면 선택과 해당 카드를 제거합니다. 기존 추가 확정 기능도 그대로 사용합니다.
- ‘식재료’: 기존 식재료 추천을 별도로 확인합니다. 종류 버튼을 다시 누르면 전체로 돌아갑니다.
- 느타리버섯볶음 카드에는 ‘같은 이름의 참고 레시피 · 재료와 조리법’이 있습니다. 식품안전나라 보유 원본 ID3364의 원재료·조리법입니다. 크래미와 양념 등 실제 재료를 그대로 보여주며, 음식 DB와 같은 배합이라고 보증하지 않습니다.

알레르기를 입력한 경우 음식 DB에 전체 원재료 정보가 없으므로 해당 음식은 기존 검사 규칙에 따라 제외됩니다. 미입력은 ‘알레르기 제외 미적용’ 안내 후 진행하며 ‘알레르기 없음’으로 변경하지 않습니다.

## 후속 확보 방안
