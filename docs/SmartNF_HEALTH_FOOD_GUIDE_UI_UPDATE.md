# 건강별 식품 선택 가이드 화면 개선

기존 계획 저장(129/130절)과 공통 화면(131절)이 적용된 프로젝트용 변경 파일입니다.

1. 서버를 종료합니다.
2. ZIP의 src/docs를 프로젝트 루트에 덮어씁니다.
3. `bash run_local.sh`로 시작하고 Ctrl+F5를 누릅니다.

DB 변경·npm 설치·가상회원/자료 재생성은 없습니다.

## 화면 확인 순서

- 건강정보 없이 방문: ‘일반 정보 둘러보기’, 식재료/음식 예시/참고 레시피 분리 확인.
- 실제 건강정보가 있으면: 목적을 바꿔도 입력된 다른 조건이 함께 유지되는지 확인.
- 신장질환·복약·개인 제한 등 보류 조건: 이유와 다음 행동 표시 확인.
- 후보 이름 검색 → 초기화 → 카드 이유/출처/성분 확인 → 선택.
- 로그인 상태: 아래에서 장보기/외식 날짜 → MyPage에 저장 → 저장 목록에서 확인.
- 가상 예시는 실제 계획에 복사하지 않습니다. 알레르기는 실제 제품/교차접촉 안전성 보장이 아닙니다.

체중 관리에는 기존 목표 확인 링크가 있습니다. 개인별 목표열량 계산과 AI 식단 제안은 후속 기능이며 이번에 계산한 것처럼 표시하지 않습니다.

자료 수집47항목은 검토용으로 유지합니다. 이번 패치는 기존 근거와 후보를 새 화면에 배치하며 새 질환/임계값/치료 효과 판정을 추가하지 않습니다.
