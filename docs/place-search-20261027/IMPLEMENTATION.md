# SmartNF 지역 검색·온라인 장보기 업데이트

- 적용일: 2026-10-27
- 확인 화면: http://localhost:8080/preview/health/diet

## 적용 방법

1. 서버가 실행 중이면 Ctrl+C로 종료합니다.
2. `health_food_nutrition.zip`을 별도 폴더에 풀고, 내부 내용을 기존 `C:\yoonfolder\hpexam\smartnf` 폴더에 병합합니다. 기존 프로젝트 자체를 삭제하거나 교체하지 않습니다.
3. 프로젝트 루트에서 `bash run_local.sh`로 서버를 시작합니다.
4. 브라우저에서 위 화면을 열고 Ctrl+F5를 누릅니다.

이번 변경에는 Java 장소 검색 컨트롤러가 포함되어 서버 재시작이 필요합니다. 인증키·DB·로그인 설정 파일은 포함하지 않습니다. 이번 변경만 적용하기 위해 별도 설치 스크립트를 실행할 필요는 없습니다.

## 바뀐 화면

| 영역 | 변경 |
| --- | --- |
| 지역 | 시·도 선택 → 시·군·구 입력/후보 선택 → 읍·면·동 입력/후보 선택. 전체 검색 지역 직접 수정 가능 |
| 장보기 | 주변 매장 / 온라인 장보기 탭 |
| 매장 유형 | 전통시장, 동네마트, 대형마트, 창고형 매장, 백화점·쇼핑센터 |
| 브랜드 | 대형마트: 이마트·홈플러스·롯데마트·하나로마트 / 창고형: 트레이더스·코스트코 / 쇼핑센터: 스타필드·롯데·신세계·현대백화점 |
| 검색어 | 선택 식품명 자동 반영, 직접 수정, 선택 식품명 다시 가져오기 |
| 외식 | 동일한 지역 선택과 음식·매장명 검색 적용 |
| 온라인 | 네이버 쇼핑·쿠팡·SSG/이마트몰·트레이더스몰·코스트코·컬리 검색 연결 |
| 상태 | 조건 변경 시 이전 결과·지도·링크 초기화. 늦게 도착한 이전 응답 무시 |

시·군·구와 읍·면·동은 입력 가능한 후보 목록(datalist) 방식입니다. 목록에 없는 최신 지역명도 입력할 수 있습니다. 읍·면·동 후보는 법정동 기준이며 행정동과 다를 수 있습니다. 세종처럼 시군구가 없는 지역은 해당 입력을 비워도 됩니다.

## 확인 순서

1. 장보기 → 주변 매장에서 경기도 → 수원시 영통구 → 영통동을 입력·선택합니다.
2. 창고형 매장 → 코스트코 또는 트레이더스를 고르고 장소 검색을 누릅니다.
3. 검색 지역·브랜드를 바꾸면 기존 결과가 사라지는지 확인합니다.
4. 온라인 장보기를 누르고 검색어를 바꾸어 각 쇼핑몰 링크가 해당 검색어로 열리는지 확인합니다.
5. 외식하기에서도 지역 입력과 음식·매장 검색이 동작하는지 확인합니다.

## 네이버 인증 설정과 현재 한계

- 인증정보 없이도 외부 네이버 지도 검색과 온라인 쇼핑몰 링크는 이용할 수 있습니다.
- SmartNF 내부 장소 목록: `NAVER_SEARCH_CLIENT_ID`, `NAVER_SEARCH_CLIENT_SECRET` 설정 필요.
- 내부 지도: `NAVER_MAP_KEY_ID` 및 해당 웹 서비스 URL 등록 필요.
- 내 주변 찾기: 브라우저 위치 동의 + Maps Geocoder/Reverse Geocoding 서비스 설정 필요. 키가 없거나 위치가 거절되면 지역 직접 선택 안내를 표시합니다.
- 위치는 버튼을 눌렀을 때만 요청하고 네이버 주소 변환에 사용합니다. 브라우저 저장소·DB에는 기록하지 않습니다. HTTPS 또는 localhost에서 이용합니다.
- 실제 네이버 인증을 사용한 지도·주소 변환과 검색 API 응답은 사용자 PC에서 후속 확인이 필요합니다.
- 네이버 장소 검색은 관련도 기준 최대 5건입니다. 거리순 전체 목록, 해당 식재료 판매·가격·재고 또는 건강 적합성 확인 기능이 아닙니다.
- 온라인은 검색 링크 연결이며 상품 API·가격 비교·장바구니·주문 연동은 포함하지 않습니다. 외부 사이트의 지역·로그인·접근 제한에 따라 추가 조작이 필요할 수 있습니다.

## 후속 반영 대기

- MyPage: 회원별 선호 지역·쇼핑몰 저장은 해당 페이지 개발 시 반영. 현재 자동 영구 저장 없음.

- 스마트 푸드 비즈니스: 상품 API·공급처별 가격·재고·장바구니 연동은 별도 업무 범위로 검토.
