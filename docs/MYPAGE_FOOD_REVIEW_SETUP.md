# 음식 관리 중심 MyPage — 구성 검토

## 적용

1. 직전 일일 기록 수정본까지 적용한 프로젝트를 백업하고 서버를 Ctrl+C로 종료합니다.
2. ZIP의 `src/`, `frontend/`, `docs/`를 프로젝트 루트에 같은 경로로 덮어씁니다.
3. `bash run_local.sh`로 재실행합니다. DB·새 Flyway 변경은 없습니다. JSX 번들을 포함했으므로 Node 빌드는 필수가 아닙니다.
4. http://localhost:8080/preview/mypage/review 를 열고 Ctrl+F5를 누릅니다. 로그인 없이 볼 수 있습니다. 기존 MyPage/체험의 ‘새 구성 미리보기’ 링크로도 이동할 수 있습니다.

이 주소는 **제안 확인용 가상 화면**입니다. 실제 회원 MyPage 전체를 교체하지 않습니다. 의견을 확인한 뒤 실제 기능을 같은 구조로 연결합니다.

## 확인할 흐름

- 왼쪽 메뉴 6개가 이해하기 쉬운지: 대시보드 / 식사·영양 / 관리항목 / 실천·측정 / 변화·피드백 / 설정.
- 대시보드 ‘오늘 식사 기록하기’ 또는 아침/점심/저녁/간식 카드를 눌러 식사 입력으로 이동합니다.
- 예시 식품을 선택하고 **g 기준 먹은 양**을 입력한 뒤 가상 기록에 추가합니다. 계정에는 저장하지 않습니다.
- ‘직접 입력 · 성분 미연결’ 음식도 추가해 보세요. 누락 성분은 0이 되지 않고, 성분별 확인 개수/전체 기록 수가 구분되어야 합니다.
- 식사 삭제, 가상 날짜 변경, 관리항목에서 식사·실천 이동, 기간별 일부 식사 기록 표시를 확인합니다.
- ‘내 대시보드 구성 바꾸기’에서 카드 표시/위·아래 순서와 로컬 구성 제안을 확인합니다. 외부 AI 생성/계정 저장은 아닙니다.
- 식품·가이드/실제 일일 기록/계정 설정은 새 탭으로 열립니다. 가상 입력이 전송되지 않습니다. 실제 기능은 기존 로그인·동의가 필요합니다.
- 식사·영양 합계는 **입력한 식품 중 확인 가능한 성분만**이며 하루 전체 섭취량·목표 충족률·완성 식단 추천이 아닙니다.
- 새로고침하면 검토 입력이 초기화됩니다. 실제 개인 정보는 입력하지 마세요.

## 푸터 확인

공통 하단 고정 푸터를 함께 적용했습니다. 짧은 화면·긴 화면에서 푸터가 화면 아래에 유지되고, 맨 아래 저장 버튼/글이 가려지지 않는지 확인하세요. 모바일은 하단 링크를 가로로 이동할 수 있습니다. AI 상담 버튼도 푸터 위에 있어야 합니다. 모바일 키보드/화면 확대·기존 다른 화면도 함께 확인이 필요합니다.

## 남은 연결

실제 식사 DB 저장/수정/삭제, 선택 식품 자동 가져오기·복귀, 식사/실천/측정 통합 조회, 외부 LLM 개인 화면 생성, 자동 피드백/리포트는 이번 검토본에서 연결되지 않았습니다. 미연결 상태를 화면에 표시했습니다.

제안 검토 후 메뉴·식사 입력 위치·대시보드 구성을 조정합니다. 검증/변경 내역은 SmartNF_IMPROVEMENTS.md 110절에 있습니다.
