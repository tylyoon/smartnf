# 건강 식생활 가이드 날짜·다중 카드 선택 (2026-11-05)

## 변경
- 상단에 오늘의 선택 날짜/날짜 조회와 장보기·조리하기·외식하기 버튼을 함께 배치. 계획 구분/준비할 계획 필터와 안내를 볼 식품 드롭다운 제거. 날짜 조회에서는 해당 날짜 전체 목록을 표시하고 저장된 일반/건강관리/질환명/계획 종류는 카드 제목으로 구분한다.
- 카드 클릭으로 선택/다시 클릭으로 해제, 선택됨 체크와 테두리, 전체 선택/선택 해제 제공. 조회 직후 자동 선택하지 않는다. 세 안내 버튼 전환은 날짜/선택 목록을 유지하고 DB 쓰기를 하지 않는다.
- 선택한 카드별로 장보기 식품·연결 재료, 외식 안내를 표시하며 서로 다른 건강관리 분류/재료를 합치지 않는다. 조리하기는 카드별 음식 이름을 펼쳐 기존 버전 검증/알레르기 조건 확인 후 원문 조리법을 읽는다. 미연결 레시피 추정 없음.
- 외식 음식별 장소 찾기는 클릭한 음식으로 검색을 연결한다. 기존 매장/온라인 검색·장보기 날짜 저장 개선 유지.
- 편집 도구는 안내 아래 배치. 목록 수정/삭제/날짜 이동은 한 카드만 선택할 때 제공해 대상 혼동 방지. 여러 카드를 조회 중에도 재료 제외는 카드마다 별도 버튼과 원래 목록 인덱스로 기존 저장 API에 반영. 나머지 목록 보존. 단순 카드 선택은 MyPage 저장 데이터 변경 아님.
- API/DB schema/저장 데이터 변경 없음. 기존 동의/알레르기/레시피 버전/revision/저장 불확실 상태와 이탈 보호 유지.

## 검증
- Node living-plan-data4개 통과, 수정JS 문법 검사.
- Chromium 실제 workspace/editor JS+대역 계정API로 상단 컨트롤/제거한 선택란 없음, 다중선택/재클릭/전체 선택·해제/키보드, 단계 전환시 선택 유지/조회만으로 쓰기 없음, 질환별 그룹/음식 조리법 펼침, 특정 목록 재료 제외 및 다른 목록 보존,5폭 페이지 넘침/JS오류 없음 확인.
- 이전 날짜·편집 취소·매장 검색 브라우저 회귀 테스트도 통과. 브라우저 테스트는 사용자 MySQL/실시간 네이버 전체 검증과 구분.

## 적용
153절 적용 프로젝트에서 서버 종료→ZIP src/docs 폴더 병합→bash run_local.sh→Ctrl+F5. DB 초기화/마이그레이션 불필요.
날짜 조회→카드 여러 개 선택→장보기/조리하기/외식하기 전환→다시 클릭해 해제 확인. MyPage 수정/삭제/계획 이동은 카드 하나 선택 후 안내 아래 관리 도구 이용.
