# 사용 흐름

## 한 끼
- 밥·주식 3종(백미밥/현미밥/찐 고구마), 단백질 2종(삶은 달걀/두부), 채소 3종(데친 브로콜리/데친 시금치/토마토), 과일·유제품 2종(사과/플레인 요구르트)을 제공합니다.
- 실제 공공 영양 DB 항목 ID를 사용합니다. 후보로 보이는 것만으로 합산하지 않고 눌러 담은 음식만 반영합니다.
- 현재 확인 가능한 탄수화물/단백질/식이섬유 값을 참고해 일부 버튼에 ‘보완 후보’를 붙입니다. 고정된 참고 문턱값이며 개인별 영양 목표·알레르기·질환 적합성 판정이 아닙니다.
- ‘음식·식재료 직접 추가’에서 두 글자 이상 검색하고 제품/조리 상태를 확인해 선택한 뒤 g을 조절합니다. MyRecipe 추가도 기존대로 가능합니다.

## 주간/월간 추천
- 주간은 선택한 시작일로부터 7일, 월간은 선택한 달의 전체 날짜입니다. 아침/점심/저녁 전체 또는 한 종류만 구성할 수 있습니다.
- 현재 후보 요리와 MyRecipe 최대 30개 안에서 배치합니다. 로컬 LLM이 정상 응답하면 ‘AI 배치 추천’, 비활성/오류/시간초과면 ‘기본 배치 추천’이라고 표시합니다.
- 후보 밖 새 요리를 자동 생성하지 않습니다. 5개로 한 달을 구성하면 반복이 생기므로 MyRecipe를 더 불러와 후보를 늘릴 수 있습니다.
- 월간은 7일씩 주차별 접기/펼치기로 표시하며 첫 주만 기본으로 펼칩니다.

## 특정 끼니 변경
- 날짜별 ‘내가 구성한 한 끼로 변경’ → 한 끼 화면으로 이동합니다.
- 이미 구성하던 한 끼는 유지합니다. 원하는 음식을 담거나 빼고 인분/g을 조절합니다.
- ‘11월 9일 저녁에 적용’처럼 대상 날짜·끼니가 표시된 버튼을 누르면 그 끼니만 교체합니다. 다른 끼니는 유지합니다.
- 변경한 구성과 g은 독립된 복사본으로 저장하여 이후 요리 재료를 편집해도 이미 적용한 다른 끼니를 함께 바꾸지 않습니다.
- 직접 변경한 끼니는 기본으로 고정합니다. 다시 추천할 때 동일 범위의 고정 끼니는 유지합니다. 고정 해제/처음 추천으로 되돌리기도 가능합니다.
- 주간/월간 초안은 탭 전환 중 각각 유지합니다. 현재 초안은 브라우저 메모리 상태이며 새로고침하면 소멸합니다. MyPage 저장 버튼으로 명시적으로 보관하세요. 저장된 기간의 고정/편집 상태를 다시 스튜디오 초안으로 복원하는 기능은 이번 범위가 아닙니다.

## 영양과 저장
- 하루 카드의 열량, 기간 전체 8개 영양 합계, 첫 7일 장보기, 전주 비교와 MyPage 저장에 교체한 한 끼를 반영합니다.
- 자료가 없는 재료는 0으로 보지 않습니다. 자동 추정 합계는 ‘일부 합계’로 구분합니다. 한 끼 저장은 확인된 음식 ID와 유효한 g이 있어야 하며 기존 최대 30개/설명 500자 제한을 지킵니다.
- 비교 중 변경 전 값은 자료가 모두 있는 항목만 표시할 수 있습니다. 전주 실제 식사 기록과 분량 확인은 기존 절차를 유지합니다.
- MyPage 계획 메모의 사람이 읽을 수 있는 ‘[식단 계획 · 저녁]’ 등의 표지를 사용해 같은 날짜·끼니의 이 화면 저장 계획만 교체합니다. 다른 기존 계획은 유지합니다. 과거 버전의 표지 없는 계획은 자동 삭제하지 않습니다.
- 여러 날짜 저장은 기존 날짜별 요청·리비전 충돌 검사·동일 요청 재시도 절차를 유지합니다. 전체 기간의 단일 DB 트랜잭션은 아닙니다. 저장 오류 시 표시된 완료 날짜 수와 안내를 확인하세요.
- 계획 저장은 실제 섭취 기록을 만들지 않습니다. 영양 차이를 특정 건강 지표 개선이나 치료 효과로 단정하지 않습니다.

## 검증
- 실제 공공 DB에서 조합 10종 항목의 존재를 확인했습니다.
- JS 순수 상태 검사: 21끼 주간/윤년 월간, 해당 끼니만 교체, 독립 분량 복사, 고정 후 재추천, 일부 영양 합계, 다른 계획 보존 및 소유 끼니 교체.
- 실제 수정 meal-studio.js의 모의 DOM/API 전체 흐름 검사: 10종 표시→주간 추천→한 끼 변경→영양 합계→월간/주간 왕복→고정 후 다시 추천→7일 계획 저장.
- 새 Java 컨트롤러 최소 Spring/Jackson 의존성 스텁 컴파일, 93끼 월간 기본 배치와 입력 오류(범위·중복·null) 검사 통과.
- 변경 JS 문법 검사 통과. 실제 모델 응답/전체 Gradle 빌드/실제 브라우저 화면/MyPage DB 저장은 사용자 PC에서 확인이 필요합니다.
