# SmartNF 본문 분류 STEP 1

## 실행

ZIP의 python/docs 폴더를 기존 smartnf 루트에 합친 뒤 Git Bash에서 실행한다. 추가 패키지 설치나 TOKEN 입력은 필요 없다.

```bash
python python/health_collection/health_classify.py --expected-count 658
```

이번 도구는 PC에 저장된 수집 자료만 읽는다. API를 호출하거나 TOKEN을 읽지 않는다. 실제 658건의 처리 결과는 사용자 PC에서 확인해야 하며 여기서 완료로 표시하지 않는다.

## 프로젝트 내부 경로

| 항목 | 위치 |
|---|---|
| 수집 원본 XML·JSON | python/health_collection/data/api/ |
| 검색어·공개/부분 승인 목록·대조 결과 | python/health_collection/data/reference/ |
| 분류 결과 | python/health_collection/data/classified/실행시각_식별자/ |
| 최신 결과 경로 | python/health_collection/data/classified/latest.json |

Windows 기준 원본 경로는 `C:\yoonfolder\hpexam\smartnf\python\health_collection\data\api\`다. 출력도 같은 프로젝트 아래 classified에 생성한다. 명령을 실행한 현재 폴더가 아닌 스크립트 위치 기준으로 경로를 찾는다.

## 처리와 결과

- 숫자 ID.json 파일만 입력으로 읽고, 같은 이름 XML의 해시와 실제 XML의 ID·본문 구조를 검사한다. 이전 last_run.json/진단 보고서는 원본 콘텐츠로 세지 않는다.
- 실제 본문은 XML에서 다시 읽는다. 편집된 JSON 본문을 검증 없이 사용하지 않는다. 원본 파일을 수정하지 않는다.
- 제목 기반 주제와 소제목·본문의 언급 주제를 구분한다. 식생활·운동·주의사항·건강 지식의 용도 후보도 기록한다. 한 자료는 여러 분류에 속할 수 있다.
- HTML은 텍스트로만 읽는다. 스크립트·스타일·URL·이미지 속성·참고문헌/출처 소제목을 분류에서 제외한다. 이미지·링크는 다운로드하지 않는다.
- index.json: ID·제목·주제·용도 후보·근거 소제목 인덱스/ID/제목/검색어·원본 경로·해시. 본문 전체를 복제하지 않는다.
- summary.json: 처리 건수·분류 건수·원본 확인 필요·미분류·부분 승인 목록 미관찰 ID·건수 일치 여부.
- report.md: 사용자가 읽을 요약 표. 실제 분류 결과의 첫 검토 자료다.
- 최신 결과는 latest.json에 경로만 기록한다. 실행마다 다른 폴더를 만들어 이전 결과를 유지하며 결과 폴더는 Git에서 제외한다.

분류는 단어 언급을 찾는 탐색 후보이며 질환 판정·개인 적합성·관리 권고가 아니다. '운동을 피해야 한다' 같은 문장이 운동 분류에 들어갈 수 있으므로 검토 전 권고에 사용하지 않는다. 모든 결과에 검토 필요와 runtime_enabled=false를 유지한다. 미분류도 삭제하지 않는다.

## 현재 확인된 목록 상태

공개 669개와 사용자 부분 승인 목록 668개는 공통 666개, 승인 관찰 목록에만 2개, 공개 목록에만 3개다. 초기 기대 688개를 전체 확정값으로 사용하지 않는다. 부분 목록에서 확인되지 않았다는 이유만으로 미승인이라고 판정하지 않는다.

현재 658개 원본 수집 성공. 기존 11개는 실제 API 응답의 본문 목록 자식이 0개로 확인됐다. 추가 5241/6574는 EMPTY_CONTENT이나 실제 구조 진단은 아직 하지 않았다. 원본 성공 수는 추가되지 않았다. 이들을 채워 넣거나 성공으로 간주하지 않는다.

실행 후 콘솔의 건수 또는 생성된 summary.json/report.md로 결과를 검토한다. TOKEN·원본 전체를 보낼 필요는 없다. 기대 658개와 다르면 입력 파일·원본 확인 필요 목록을 점검한다.

검증: Python 테스트 27개 및 Node 추출기 검사 통과. 실제 Windows 658개 분류는 실행 대기다.

## 사용자 결과 검토 후 보완

제공된 요약/인덱스의 658개 ID와 집계는 일치했다. 상세는 `HEALTH_CLASSIFICATION_REVIEW.md` 참조. 제목과 기존 원본 해시를 고정한 분류명 검토 16건을 `classification_title_review.json`에 추가했다. 실제 본문 검토 승인은 아니다. 원본이 같을 때만 자동 분류 결과에 보완을 적용하며, 제목·해시가 바뀌면 적용하지 않는다.

명령은 기존과 같다. 원본이 동일하면 주제 미분류 15건과 용도 미분류 1건을 보완하고, 제목 분류 검토 반영 16건이 예상된다. 실제 결과로 확인한다. 승인 관찰 목록 미확인 3건은 유지하며 공개 연결 대기로 표시한다. 다음 본문 검토 후보 14건은 `core_health_review_candidates.json`으로 관리한다. 나머지 자료도 유지한다.

## 고혈압 실제 본문 검토 후 정제 보완

사용자 전체 data.zip의 658개 XML·JSON을 검사했고 해시·ID·제목·소제목 일치 검사에 통과했다. 5303 한 자료에서 번역 위젯·JS 조각이 섞인 63개 항목을 확인해 정제했다. 위젯 전용 조각 제외와 본문 뒤 표시 문구 제거를 구분하고 건강 본문·원본·section_index를 보존한다. 임의의 영문 본문을 삭제하지 않는다.

같은 명령으로 실행하면 기존 집계를 유지하면서 번역 위젯 정제 1개 자료/63개 항목이 표시된다. 받은 실제 전체 자료로도 658건 재분류에 통과했다. 임상 규칙 승인·페이지 변경은 포함하지 않는다. 고혈압 3개 본문 검토와 기존 관리항목 6개 연결안은 `HEALTH_BP_BODY_REVIEW.md` 및 `data/reference/bp_body_review.json` 참조.
