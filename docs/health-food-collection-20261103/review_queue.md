# 후속 검토 목록

자료 수집 완료와 실제 서비스 적용 승인은 구분한다. 아래 항목은 기존 앱의 동작을 수정하지 않고 정리했다.

| ID | 확인할 항목 | 관련 출처/근거 | 처리 방향 |
|---|---|---|---|
| R01 | 소금 추가량과 하루 총량의 기준 차이 | amc-bp / kdca-bp-shopping | 같은 숫자 기준으로 합치지 않고 적용 대상·정의를 검토 |
| R02 | 견과류가 한쪽에서는 선택 예시, 다른 쪽에서는 분량 주의 | kdca-bp-shopping / amc-weight | ‘좋음/나쁨’ 단일 표기 대신 관리 목적·양·가공 조건 구분 |
| R03 | 혈압 식품 예시와 신장질환 제한 | kdca-bp-shopping / amc-ckd / kdigo-ckd-2024 | 단계·검사·동반질환에 따른 별도 검토. 자동 추천 보류 유지 |
| R04 | 당뇨 안내 음료명만으로 가당 여부를 알 수 없음 | kdca-diabetes HE-025 | 제품 당류 확인 없이 무제한/무가당으로 분류하지 않음 |
| R05 | 콜레스테롤 관련 식품 주의 문구의 적용 범위 | amc-lipid / kdca-lipid | 대상·갱신 시점·전문 지침을 대조. 공통 금지 규칙으로 전환 안 함 |
| R06 | 식품교환단위와100g/100mL의 차이 | kda-exchange-intro / kda-meat-exchange | 원자료 기준량/조리 상태와 교환량을 별도 필드로 유지 |
| R07 | 식단 이미지 속 개별 메뉴 재확인 | kdca-heart-menu / 기존5음식 연결 | 이번 텍스트에서는 개별 메뉴명을 재검증하지 못함. 원문 시각 자료·이용 조건 검토 필요 |
| R08 | 저지방 어육류·무염·무가당 등 조건 | 병원/학회/질병관리청 | 이름만으로 특정 코드 승인 금지. 제품·부위·조리 조건 대조 |
| R09 | 근거 수준과 수치 기준의 검토 | 전체 | 기관 교육 본문은 수집됨. 근거 등급/최신 진료지침 대조는 별도 |
| R10 | 자료 이용 허용 범위 | kdca-rights 및 각 기관 | 공개 접근을 상업적 복제/변형/RAG 허용으로 간주하지 않음 |
| R11 | 성분 결측과 코드 매칭 | 기존 영양자료/후보 | 결측을0으로 치환하지 않고 이번에 새 코드 연결을 생성하지 않음 |
| R12 | 질환 범위 밖 사용 | 전체 | 소아·임신·수유·복약/개인 제한을 일반 성인 규칙에 자동 포함하지 않음 |

정책 참조: https://health.kdca.go.kr/healthinfo/biz/health/useGuidance/cpyrhtPolicy.do

의료적 내용은 검토용 사실 요약이다. 출처끼리 다른 부분을 임의로 평균/투표/LLM으로 해결하지 않는다. 단계/검사값 수집이 필요하다면 기존 건강정보 동의·최소 수집·목적/보관 정책부터 별도 설계한다.
