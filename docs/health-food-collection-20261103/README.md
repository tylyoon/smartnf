## 기존 조사에서 진전된 부분

- 기존9출처의 관련 본문을 다시 확인하고, 추가로 대한당뇨병학회의 기본원칙/식품교환표 소개, 병원 신장 식사요법, KDIGO2024 조건별 안내를 구조화했다.
- 학회 어육류군 페이지의 설명 본문을 이번에는 확인했다. 이전 ‘세부 표 확인 부족’은 개별 식품의 지방군/원자료 코드 대응에서는 계속 유효하다.
- 고혈압 자료는 2026-10-29, 혈당은2026-10-23, 지질은2026-04-22, 탄수화물 안내는2026-09-21 갱신 표시를 기록했다. 병원/학회에서 확인되지 않은 갱신일은 null로 두었다. 수집일을 갱신일로 대체하지 않는다.
- 심뇌혈관 식품군 본문은 확인했다. 기존 연결에 사용한 식단 그림의 개별 음식명은 이번 텍스트만으로 다시 확인하지 않아 코드 연결 확정 대상으로 삼지 않았다.

## 이후 결정할 수 있는 화면 방향

자료에는 식품 예시와 성분 안내가 모두 있다. 따라서 ‘관리 목적 → 확인할 성분/조리 조건 → 출처가 있는 식품 예시 → 주의·예외’의 구성이 검토 가능하다. 다만 이번에는 화면안을 확정하거나 배포하지 않는다.

다음은 review_queue의 미해결 항목을 확인하면서 사용할 근거와 보류할 근거를 결정하는 단계다. 특정 질환이 있다는 이유만으로 모든 후보를 개인에게 추천하지 않는다. 일일 영양 섭취량/권장량 비교 기능도 다시 도입하지 않는다.

## 출처 열기

기관 원문 링크는 sources.json과 CSV에 정확히 들어 있다. 브라우저 검색 결과의 내부 참조 번호는 추적용 보조값이며, 사용자용 원문 링크는 URL을 사용한다. 자료 이용 정책은 확인했으나 개별 항목의 상업 재배포 허락을 취득한 것은 아니다. API 신규키 신청/유료 지침 구매/외부 연락은 수행하지 않았다.
