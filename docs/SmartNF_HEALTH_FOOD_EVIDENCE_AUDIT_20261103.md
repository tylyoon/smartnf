# SmartNF 질환별 식품·영양 근거 보유 현황과 추가 확보처

조사일: 2026-11-03. 범위는 공개 보유 데이터·추천 규칙·이전 감사 목록과 공개 기관 자료다. 개인 DB/건강정보·회원자료는 조회하지 않았다. 화면/추천 로직은 수정하지 않았다.

## 조사 결론

**원본 영양 DB에는 질환에 좋음/나쁨을 직접 판정하는 항목이 없다. 그러나 별도의 기존 가이드에는 질환별 식품 선택 근거와 연결 후보가 이미 있다.** 새 자료 수집에 앞서 기존 연결의 근거 수준·최신성·예외를 재검토하는 것이 우선이다.

- 원본: 식품코드·이름·조리 상태·기준량·출처·성분값. 단독으로 질환 적합 여부를 뜻하지 않는다.
- 기관 안내: 식품명/식품군·조리·분량·주의 정보를 제공한다. 일반 식품 선택의 근거로 검토할 수 있다.
- 프로젝트 연결: 기관 표현을 특정 원자료 식품코드와 대조한 자체 규칙이다. 원자료 제공기관이 개별 코드를 질환별 인증한 것으로 표시하면 안 된다.
- 레시피 재료 연결: 특정 재료가 등장한다는 관계다. 완성 음식 전체의 질환 적합성·영양값·알레르기 안전성을 보증하지 않는다.

## 3. 가이드에 적용할 방향

| 조건 | 근거에서 확인할 축 | 사용자가 이해할 표현 |
|---|---|---|
| 혈압 | 나트륨·양념·가공 상태, 식품군 선택 | 나트륨과 조리 상태 확인 |
| 혈당 | 탄수화물·식이섬유·식사 구성/분량 | 탄수화물과 실제 먹을 양 확인 |
| 혈중 지질 | 포화/트랜스지방·식이섬유·전체 식사 | 지방 종류와 식이섬유 확인 |
| 감량 | 열량·첨가당/기름·전체 분량 | 기준 열량과 조리·분량 확인 |
| 신장질환 | 단계·투석·혈중 전해질·동반질환 등 | 개인 식사 제한 확인 필요 |

위 표는 서비스 설계용 검토 축이며 개인 영양 처방이 아니다. 특히 혈압용 칼륨 안내를 신장질환에 그대로 적용하지 않는다. KDIGO는 고칼륨혈증 등 조건에서 개별화된 접근을 설명한다. 병원의 요약 안내와 전문 지침의 적용 대상이 다르면 자동 병합하지 않는다.

권장 실행 순서:

1. 기존9개 근거의 현재 본문·날짜·이용 조건을 재검토한다. 고혈압 자료는 이번 조회에서 2026-10-29 갱신이 표시되어 기존 확인일2026-10-27보다 뒤이므로 기존 연결의 재검토가 필요하다.
2. 근거를 ‘식품명 직접 언급 / 식품군 안내 / 영양성분 안내 / 재료 활용 참고 레시피’로 분리한다. 안내마다 출처·절·갱신/확인일·적용 대상·제외 조건·이용 상태·검토 상태를 저장한다.
3. 초기 범위는 혈압·혈당·지질·감량으로 유지한다. 성분값만으로 질환 추천 점수나 임의 임계값을 만들지 않는다.
4. 음식 이름만 맞는 참고 연결을 치료식으로 승격하지 않는다. 신장질환 등 복합 조건 보류를 해제하지 않는다.
5. 근거 정리가 끝난 뒤 화면을 바꾼다. 승인되지 않은 신규 규칙은 배포하지 않는다. 개인 건강정보를 외부 검색/LLM에 전송할 필요는 없다.
