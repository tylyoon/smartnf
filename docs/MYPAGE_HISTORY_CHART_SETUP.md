# 일자별 관리 예시 — 기간 선택·그래프 적용

직전 계정 설정/일자별 예시 ZIP을 적용한 프로젝트가 기준입니다.

1. 실행 서버를 Ctrl+C로 종료합니다.
2. ZIP의 `frontend/`, `src/`, `docs/` 파일을 프로젝트 루트에 같은 경로로 덮어씁니다.
3. `bash run_local.sh`로 재실행합니다. DB 변경/추가 설정/수동 SQL은 없습니다. 빌드된 JavaScript를 포함하므로 Node 빌드도 필수가 아닙니다.
4. 로그인 후 http://localhost:8080/mypage/examples 에서 Ctrl+F5를 누릅니다.

확인할 내용:

- 기본 30일, 최근 7일·30일·90일·전체 120일 버튼과 표의 날짜 수가 맞는지.
- 직접 시작/종료일을 선택하고 ‘기간 적용’을 누르면 그래프·표가 같이 바뀌는지.
- 역순 기간은 안내가 나오고 기존 기간을 유지하는지. 하루만 선택해도 점/표가 표시되는지.
- 혈압 두 선과 체중 별도 그래프의 단위/축 눈금, 미기록 날짜의 선 끊김.
- 그래프 점을 마우스/키보드로 선택하면 아래 상세 내용이 표시되는지.
- 실천 날짜를 선택하면 해당 메모가 표시되는지. 미기록과 쉬었다는 기록이 구별되는지.
- ③ 규칙적 식사 예시는 수치가 없어 혈압·체중에 ‘기록 없음’이 표시되는지.
- 모바일에서 그래프와 표를 각각 가로로 확인하고, 페이지 전체에 불필요한 가로 넘침이 없는지.

빠른 기간은 **예시 마지막 날짜 2026-11-01 기준**입니다. 120일 자료는 기존 7일 가상 패턴을 반복한 시연용이며 실제 건강 변화나 실천 효과가 아닙니다. 계정에 저장하거나 실제 기록으로 복사하지 않습니다.

소스 수정 시에만:

```bash
cd frontend
npm ci
npm run build:mypage
node --test tests/example-history.test.mjs
```

실제 날짜별 개인 기록 저장/분석·피드백은 후속 작업입니다. 이번에 실행한 검사는 개선 문서 108절에 기록했습니다. 실제 브라우저 화면은 사용자 확인 대기입니다.
