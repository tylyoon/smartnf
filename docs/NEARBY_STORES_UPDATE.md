# 가까운 매장 검색 업데이트

## 적용

1. 서버를 Ctrl+C로 종료합니다.
2. ZIP의 src와 docs를 기존 smartnf 프로젝트 루트에 병합·덮어쓰기합니다.
3. bash run_local.sh 로 재시작하고 브라우저에서 Ctrl+F5를 누릅니다.
4. 건강 식생활 관리 가이드 → 장보기 → 주변 매장을 확인합니다.

## 확인 예

경기도 → 수원시 영통구를 입력하고 창고형 매장 → 코스트코를 선택합니다.
검색 범위는 기본값 ‘가까운 매장·인접 지역 포함’, 직선거리30km로 둡니다.
첫 확인 시 식재료·음식·매장 검색어는 비워 주세요.
지점이 수원시 밖에 있어도 후보로 반환되고30km 안이면 표시하며 거리를 정렬합니다.
동일하게 이마트·홈플러스·롯데마트·하나로마트·트레이더스·스타필드·롯데/신세계/현대백화점에도 적용됩니다.
전체 브랜드에서는 해당 매장 유형의 검색 후보를 정렬합니다.

검색 지역에는 정확한 도로명 주소도 직접 입력할 수 있습니다.
Geocoding에서 단일 위치를 확인하지 못하면 더 구체적인 주소를 입력해 주세요.
지역명 입력 시 지도서비스가 반환한 좌표를 기준으로 하며 실제 사용자 위치나 정확한 행정구역 중심은 아닙니다.
현재 위치 버튼은 동의 후 좌표를 기준으로 사용하며, 주소를 수동 변경하면 해제됩니다.
화면에 기준 주소를 표시하고 지도에는 기준 위치와 번호 있는 지점을 함께 표시합니다.
입력한 위치와 좌표는 이번 화면 메모리에서만 사용하며 저장하지 않습니다.

## 전제와 한계

기존 API HUB 매장 검색, 지도키, SecurityConfig, run_local.sh 설정은 유지합니다.
Maps에서 Dynamic Map·Geocoding·Reverse Geocoding을 선택해야 합니다.
새 인증정보 입력이나 Java 변경은 없습니다.
한 번의 가까운 매장 검색에서 지역/상위시군/시도 최대3회 지역검색, 각최대5개 결과를 모읍니다.
주소 조회는 별도로 호출됩니다. 실제 호출량은 네이버 콘솔에서 확인할 수 있습니다.
브랜드·업종을 확인하고 중복·좌표 누락·거리 범위 밖 항목을 제외합니다.
검색된 후보들 사이의 직선거리 순이며 전국 모든 지점을 조회한 최단거리 보장은 아닙니다.
이동거리·소요시간·매장 재고는 제공하지 않습니다. 0건을 매장 부재로 단정하지 않습니다.
더 완전한 후보 확보는 공식 브랜드별 지점 목록·좌표와 갱신 절차를 확보한 뒤 확장할 수 있습니다.

## 검증

거리 공식 기준값, 반경, 좌표 형식, 정렬, 브랜드10종/전체브랜드 유형 검사를 통과했습니다.
모의 브라우저에서 인접지역·중복·조회 상한·지도 기준점·번호·주소실패·모바일 표시를 확인했습니다.
실제 네이버 인증이 적용된 사용자 PC의 결과는 적용 후 확인해야 합니다.
