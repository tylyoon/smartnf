# SmartNF 헬스케어 1~4 적용 결과 및 후속 순서

작성일: 2026-10-27

## 1. 개발 순서 확정

1. 현재 헬스케어의 데이터 정리·영양정보·근거 기반 식품선택·식생활 안내(1~4)를 먼저 보완하고 사용자 화면을 확인한다.
2. 헬스케어가 정리된 뒤 로그인·회원가입·Spring Security 및 회원별 저장 기반을 구현한다.
3. 회원 기반 위에서 AI 레시피·식단(5)과 MyPage(6)를 구현한다. 이번에는 두 페이지와 인증 구조를 변경하지 않았다.
4. 하나의 SmartNF로 계속 개발하고, 최종적으로 헬스케어를 세미 제출용으로 추출한다. 현재부터 별도 프로젝트로 나누지 않는다.

## 4. 화면 확인 방법

1. 수정 압축파일을 기존 smartnf 폴더에 병합한다. 기존 프로젝트를 삭제하거나 새 프로젝트로 바꾸지 않는다.
2. 실행 중인 서버를 Ctrl+C로 종료하고 `bash run_local.sh`로 다시 실행한 뒤 브라우저에서 Ctrl+F5를 누른다.
3. 식재료·식품 영양정보에서 두부를 검색해 상세표의 칼슘·철·비타민 C·D·B12와 출처를 확인한다. 수치 없는 항목은 자료 없음/미측정/미량 등으로 나타나는 것이 정상이다.
4. 식재료를 나의 선택에 담고 건강 식생활 관리 가이드로 이동한다. 장보기에는 선택 재료의 기준량·원문 상태를, 조리하기에는 ‘선택 재료 활용 참고 조리법’을 확인한다.
5. 참고 조리법을 선택하면 해당 레시피의 장보기 재료·조리단계·외식 확인사항이 표시된다. 참고 선택만으로 나의 선택 식품·확정등록에 새 항목이 추가되지 않는지 확인한다.
6. 건강별 식품 선택 가이드에서 추천 이유·출처를 펼쳐 근거 요약·절·확인일을 확인한다. 현재 건강정보에서 조건을 확정한 상태여야 해당 조건의 후보가 나온다.
7. 알레르기·선택 해제·다른 식품 변경 후 이전 안내가 남지 않는지 확인한다. 공식 원재료가 확인되지 않은 복합 조리법은 알레르기 설정 시 보류한다.

## 5. 검증

- Python 자동검사6개 통과(내보내기 무결성·결측·미량·0 보존·연결 도구).
- 영양22983개 레코드의17필드·청크 SHA256·기존12영양값 보존 대조 통과.
- 추천 엔진: 다중조건 교집합·미입력 정책·알레르기·개인 제한·원문 연결 검사 통과.
- 레시피: 105종 출처 연결, 재료 분리, 가정단위 원문, 코드 자동확정 금지, 소수분량 숫자 보존 검사 통과.
- 새 품질상태:1156개 레시피·6개 표시보류·5개 건강근거 보류·추천/품질 버전 일치 검사 통과.
- 브라우저:17영양필드, 식재료→식생활 안내, 참고 레시피 선택, 자동등록 없음, 번호1회표시, 지도검색어, 알레르기 변경, 품질파일 실패 시 이전 카드 제거 검사 통과.
- 기존 추천 카테고리·선택/해제·확정등록 분리·다중질환·미입력 정책·네이버 무인증 대체 링크 검사 통과.
- 화면폭320·390·1440에서 가로 넘침과 JavaScript 오류 없음. 모바일 화면 직접 확인.
- 이번 환경에서 실제 Spring Boot·MySQL 통합 실행이나 네이버 운영 인증 검사는 하지 않았다. 사용자 Windows 환경의 실행 확인이 남아 있다.

## 6. 운영·후속 목록

- 새 품질파일이 없거나 추천 버전과 다르면 추천을 멈추고 다시 불러오기 안내를 표시한다. 업데이트할 때 데이터·JS·템플릿을 함께 반영해야 한다.
- Python은 원본 검사→품질상태표→영양 버전 내보내기→추천 스냅샷 생성 순서로 관리한다. 원본과 검토전 후보를 운영 규칙과 구분한다.
- 건강 원문 재조회·승인 대조는 보류목록으로 관리한다. 소스 원본·TOKEN·비밀번호·DB 설정은 이번 파일에 포함하지 않았다.
- 로그인·회원가입 전 현재 확정 목록은 브라우저의 임시확정 상태다. 회원 DB 저장이라고 표현하지 않는다.
- Backend 후속: 회원별 건강정보·관리항목·선택식품 저장, 확정/삭제 API·권한검사·버전 기록.
- AI 레시피·식단 후속: 검토된 재료코드·분량·영양기준·알레르기·다중질환 제약을 검증한 식단 구성. 월간3끼는 이 기반 위에서 구현.
- MyPage 후속: 확정 등록 항목 조회·삭제, 계획과 실제 식사·건강기록, 기간별 피드백. 이번 화면에서 자동 생성하지 않음.
