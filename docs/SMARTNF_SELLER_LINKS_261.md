# SmartNF 261: 헬스케어 온라인 사이트를 AI 식단 가격 비교에 연결

## 적용 범위
260 적용본 위에 이 ZIP을 덮어쓰세요. 서버를 재시작하고 가격 비교 화면을 새로고침합니다. DB 변경은 없습니다.

- 헬스케어 코드의 네이버쇼핑·쿠팡·SSG·트레이더스·코스트코·컬리 검색 주소를 AI 식단 비교 화면에 추가했습니다.
- 기존 다나와·에누리·오아시스·이마트몰·롯데마트·홈플러스/전단 링크를 유지합니다.
- 링크 영역을 재료/필요량 입력 바로 아래로 올려 정기 상품 카드에 묻히지 않게 했습니다.
- 재료명이 있으면 검색 결과, 재료명이 없으면 사이트 홈을 새 창으로 엽니다. 링크를 추가한 것이 가격 자동 수집·재고/배송비 확인 성공을 의미하지 않습니다.
- 핵심 링크6종의 존재, 재료명/빈 검색어 처리, 새 창 보호 속성, 상단 배치를 실제 JS 실행으로 검사했습니다. 관련 기존 Node 테스트2건과 JS 문법 검사 통과. 외부 사이트 실접속 및 실제 로그인 브라우저는 미검증입니다.

## 장보기 미확인 가격에 관하여
링크만 추가해도 장보기 조사가격이 채워지는 것은 아닙니다. 현재 확보한 KAMIS·참가격 파일에는 올리브오일·정제염·후추·원재료 생크림의 적합한 자료가 없고, 우유는 g 필요량과 mL 조사가격을 연결할 확인값이 없는 상태입니다.
기존 사용자 기준에 따라 장보기 예상금액은 KAMIS·참가격만 사용하도록 유지했습니다. 미확인 품목의 실제 조사자료 확보 또는 '검증된 판매가 기반 보완 참고금액' 같은 별도 기준 결정이 남아 있습니다. 해당 기준 변경은 이번 ZIP에 적용하지 않았습니다. g↔mL를 같은 값으로 채우거나 근거 없는 가격을 생성하지 않았습니다.
