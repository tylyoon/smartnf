# SmartNF 기간 배치 v1

정책 버전 SmartNF-period-20261111-v2. 아래 점수는 임상 검증 점수가 아닌 후보 정렬용 휴리스틱입니다.

반복 횟수×0.7 + 직전 동일 요리 4 + 당일 중복 3 + 선택한 영양 조건 가점/감점으로 낮은 점수부터 배치합니다. 동점은 원래 후보 순서입니다. 일반 에너지 비율은 확인된 열량/3대 영양소 자료에 한해 참고 범위 이탈을 반영합니다. 나트륨 밀도는 sodium/energy/4를 최대4로 제한, 식이섬유 밀도는 1/(1+fiber×1000/energy)를 사용합니다. 이 정규화 계수는 공식 지침 수치가 아닙니다. 입력 열량은 3끼 배치 단계에서 목표와 배치분의 차이, 나트륨 상한은 초과 비율×2로 참고합니다. 공급 자료가 부족한 값은 임의로 0을 만들어 목표 달성으로 평가하지 않습니다.

고정 기능을 제거했으며 다시 추천하면 기존 변경 끼니도 새로 배치합니다. 제외 재료는 명시된 문자열 기준이며 숨은 알레르기나 임상 적합성 판정을 제공하지 않습니다. 목표 미충족을 해결하기 위해 새 요리·인분을 임의 생성하지 않습니다.
