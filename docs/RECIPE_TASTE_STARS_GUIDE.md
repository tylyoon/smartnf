# 맛 입력 통합과 별점 v2 (194절)

## 표시·편집

AI 분류·예상 맛을 접지 않고 표시한다. 기본적으로 레시피 카드도 펼쳐 시작하며 사용자가 음식명을 눌러 접을 수 있다. 분석 요청 버튼과 ‘제안’ 문구를 제거했다. 현재 분류·맛을 먼저 표시하고 AI 자료가 없으면 레시피별로 자동 요청한다. 요청은 순서대로 실행하며 준비 중임을 알린다.

같은 입력란에서 맛 강도 6축, 식감·향을 수정한다. 별도 ‘실제 맛’ 입력란과 좋음/보통/아쉬움, 예/아니요 선택란을 제거했다. 먹어본 뒤 수정한 평가 체크로 예상값 수정과 실제 평가를 구분한다. 단일 ‘분류 및 평가 저장’ 버튼으로 저장한다.

음식명 옆에 내 입맛과 다시 먹고 싶은 정도 2개 별점 그룹을 둔다. 각각 1~5점이며 미평가는 null로 보관한다. 평가 해제도 제공한다. 라디오 그룹 의미, 별마다 점수 이름, 화살표/Home/End 키 이동을 지원한다. 별점 클릭이 레시피의 접기/펼치기를 작동시키지 않는다. 좁은 화면에서는 별점을 음식명 아래로 배치한다.

## 데이터·호환

기존 V22 및 Features 구조는 유지한다. Feedback에 likingStars/againStars(각각 nullable 1~5), 실제 texture/aroma를 추가한다. 기존 liking/again/actual/adjustments JSON도 읽을 수 있다. 과거 좋아요→5/보통→3/아쉬워요→1, 재섭취 예→5/아니요→1은 표시용 변환이다. 과거에 5점 척도로 평가했다는 의미는 아니다. 새 평가 저장부터 정확한 1~5점을 보관한다.

V23 my_recipe_prediction은 회원+레시피 번호 복합키와 삭제 CASCADE로 첫 보관 AI 기준값을 따로 저장한다. 실제 평가가 AI 기준값을 덮어쓰지 않는다. 기존 LOCAL_LLM 값은 재사용하고 수정 전 보관한다. 예전에 USER 값으로 이미 덮어쓴 뒤 원본이 없었던 AI 값은 과거 값으로 복원할 수 없다. 이 경우 자동 분석으로 새 기준을 만든다. 캐시는 레시피가 삭제되면 함께 지운다.

분석 캐시 저장은 사용자 평가의 revision을 변경하지 않는다. 자동 응답이 도착하기 전에 수정·저장한 화면은 덮어쓰지 않는다. AI 캐시만 존재해도 목록의 나라/역할 필터에 반영한다. 실제 모델 실패 때 숫자를 만들지 않고 현재 값을 유지한다. 자동 분석이 완료된 기준은 다음 방문에 DB에서 읽는다. 이 단계에서는 강제 재분석 UI를 제공하지 않는다.

별점만 저장한 경우 actual이 비어 있으며 이를 실제 맛 강도로 취급하지 않는다. 먹어본 뒤 수정 체크를 한 입력값만 actual 및 실제 식감·향으로 저장한다. 체크하지 않으면 예상값 수정이다. 실제 식사 기록을 자동 생성하지 않는다. MyRecipe는 기존처럼 MyPage에 연결된 계정별 저장소다.

취향 평균은 각 축에 유효한 서로 다른 음식 3개 이상이 있을 때 계산한다. 내 입맛 4~5점, 재섭취 미평가 또는 3점 이상인 실제 강도를 선호 자료로 사용한다. 낮은 별점(1~2)은 취향 정렬에 불리하게 반영한다. 예전 ‘너무 강함’ 평가의 보정은 기존 자료를 읽을 때 유지하지만 통합 양식에서 새로 저장하면 현재 입력한 강도를 사용한다. 모델 가중치 학습/파인튜닝은 아니다. 식감·향은 실제 평가로 저장하지만 아직 정렬 점수로 수치화하지 않는다.

## 검증

- Java21 + 실제 Spring/Jackson API 컴파일 및 실제 JdbcTemplate/H2 검사. V22→V23 테이블 생성, 과거 JSON 읽기, 새 1~5점·식감 저장/조회, 회원 분리·revision, AI 기준값 분리·캐시, 삭제 CASCADE 확인. 회원 식별은 검사 전용 대체 클래스이며 Spring Security 필터 전체 검사는 아니다.
- 실제 Java HTTP 어댑터는 로컬 응답 fixture로 확인했다. 실제 Qwen 추론 품질 검사가 아니다.
- 실제 JS/JSDOM: 자동 표시·자동 분석, 단일 입력란, 별점 2종·과거 값 변환, 키보드 이동, 저장 및 AI 원본 분리 검사.
- 기존 환경과 동일하게 전체 Gradle 빌드와 실제 MySQL, Chromium 기반 PC/모바일 시각 검증은 실행하지 못했다. 사용자 PC에서 V23 적용, 자동 분석, 별점 저장·재방문 복원을 확인해야 한다.

범위는 MyRecipe와 기존 취향 정렬이다. Gemini 새 레시피 생성에 프로필 전달 기능을 추가한 수정은 아니다.
