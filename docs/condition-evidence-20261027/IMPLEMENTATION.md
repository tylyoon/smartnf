# 관리조건별 식품 추천 근거 연결 보완

작성일: 2026-10-27 / 기존 메뉴·건강입력·로그인·DB·AI식단·MyPage 구성 유지

## 1. 적용 내용

추천 후보215개의 질환·목표별 연결470개를 구조화했다. 혈압·혈중지질·혈당·체중 관리 각각에 대해 목적·확인할 영양정보·함께 볼 조건·근거 출처·적용 한계를 기록한다. 식품명 대조, 식품군 방향 적용, 공식 식단 예시, 조리 형태 예시, 추천 재료 활용을 구분해 표시한다.

공식 자료에 특정 식품명이 있는 것과 어떤 식품군을 활용하라는 일반 방향은 다르다. 다른 질환의 문서에서 식품명을 확인한 경우에는 ‘식품명 확인 자료’로 표시하며, 해당 질환에 대한 직접 권고처럼 표시하지 않는다.

| 관리조건 | 현재 연결 범위 | 화면에서 확인할 내용 |
|---|---|---|
| 혈압 | 기존 원재료·곡물·음식 예시 및 재료 활용 후보 | 원재료·양념·가공상태, 표시 기준량, 나트륨 정보 확인 방향 |
| 혈중 지질 | 식품군 방향·곡물·두부 등 기존 후보 | 포화지방·식이섬유·전체 식사량 및 실제 조리상태 확인 방향 |
| 혈당 | 기존 채소·버섯·곡물 선택 방향과 활용 후보 | 탄수화물·분량·식품군·첨가당 확인 방향 |
| 체중 | 기존 채소·곡물 선택 방향과 활용 후보 | 실제 열량·분량·간식을 포함한 식사량 확인 방향 |

이 표는 개인 처방 기준이 아니다. 새 영양 임계값·건강효과 예측·섭취량 계산을 추가하지 않았다. 신장질환·기타 질환의 기존 보류와 미입력 진행 정책은 유지한다.

## 2. 조건에 맞는 연결 재료만 표시

‘순두부 사과 소스 오이무침’의 현재 연결 근거 예시:

- 혈당 관리: 오이.
- 혈중 지질 관리: 두부·오이.
- 레시피에 등장하는 모든 재료가 각 질환에 추천된다는 의미가 아니다. 다른 재료·양념·분량과 완성 음식의 적합성은 미판정 상태를 유지한다.

레시피에 식재료의 영양값을 옮기거나 실제 재료코드를 확정하지 않는다. 추천 카드의 ‘확인할 영양정보’는 확인 방향이며, 미확인 레시피 영양수치가 채워졌다는 의미가 아니다.

## 6. 화면 확인

1. 업데이트 파일을 기존 smartnf 폴더에 병합한 뒤 서버 재시작과 Ctrl+F5를 진행한다.
2. 건강정보에서 현재 확인할 질환·목표를 확정한다. 예를 들어 기존 가상 예시 또는 본인이 입력한 상태를 사용한다. 임의로 실제 질환을 만들 필요는 없다.
3. 건강별 식품 선택 가이드의 ‘추천 기준과 정보 확보 상태’를 펼친다. ‘내 조건의 식품 선택 기준’에서 현재 조건만 나오는지 확인한다.
4. 추천 카드의 ‘추천 이유·출처 확인’을 펼친다. 연결 방식, 현재 조건에 해당하는 재료, 확인할 영양정보, 출처의 역할·절·확인일을 확인한다.
5. 조건을 바꾸어 확정하면 이전 조건의 근거가 남지 않는지 확인한다. 추천 재료가 있다고 완성 음식의 질환 적합성이 승인됐다는 의미는 아니다.
6. 카드의 식품선택·해제와 장보기·조리·외식 연결은 기존대로 이용한다. 로그인·회원가입·AI식단·MyPage는 이번 작업에서 변경하지 않았다.
