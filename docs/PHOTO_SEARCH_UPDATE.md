# 변경 동작과 확인 방법

## 자동 검색
- 못 찾은 음식은 마지막 검색 이후 1시간이 지나면 재검색 대상입니다. 대상 점검은 기존처럼 작업 완료 5분 뒤 최대 10개입니다. 서버가 켜져 있어야 합니다.
- 원문으로 전체 출처를 먼저 검색하고 못 찾으면 로컬 LLM에 대표 음식명 하나를 요청합니다.
- 예: 김치 양파 국 → 김치국 → kimchi soup. 영어는 검증된 사전 매핑만 사용하며 LLM이 생성한 임의 영문을 사용하지 않습니다.
- 모델은 기존 SMARTNF_LOCAL_LLM_ENABLED와 SMARTNF_LLM_PORT를 사용합니다. run_local.sh의 기존 자체 모델 서버를 공유합니다. 재학습 기능이 아닙니다.
- 원문에 없는 재료 추가, 국→찌개 등 조리법 변경, 김치·된장 등 핵심 요소 삭제를 검사해 잘못된 제안을 버립니다. 완벽한 의미 판단은 아니므로 사진 검토는 유지합니다.
- LLM이 꺼져 있거나 연결 오류·시간초과·응답 검증 실패이면 기본 검색어로 진행합니다. 김치 양파 국→김치국은 기본 규칙도 제공합니다.
- 대표명과 모델 상태는 해당 음식의 최근 검색 기록에 표시합니다.

## 두 종류의 제외
- ‘이 사진만 제외’: 사진 주소를 제외 이력에 저장하고 후보를 비운 뒤 다른 사진을 검색 대기합니다. 같은 음식에서 그 주소는 다시 제안하지 않습니다.
- ‘검색 제외’: 해당 음식의 자동 검색을 중단합니다. ‘제외 해제’하면 다시 대기합니다.
- 이전 코드에서 사진 후보를 제외해 멈춘 건은 V21에서 제외 사진 이력을 보존하고 다시 검색 대상으로 전환합니다. 명시적인 검색 제외와 승인 사진은 유지합니다.
- URL이 다른 같은 사진까지 픽셀/시각 유사도로 판별하는 기능은 이번 범위에 없습니다.
- 승인/사진 제외 제출에 현재 사진 주소도 포함해 오래된 화면의 버튼으로 새 후보를 잘못 처리하지 않도록 합니다.

## 키 설정 이후 확인
- ‘미발견 음식 검색 대기열 갱신’을 누르면 승인·검토 대기·명시적 검색 제외 건을 유지하고 미발견 건만 READY로 전환합니다.
- 상단 ‘키 설정됨’은 키를 읽었다는 뜻입니다. ‘후보 발견/결과 없음’이 새로 표시되어야 실제 API 응답을 처리한 것입니다.
- 국내 출처 오류는 원문 키/URL을 노출하지 않고 HTTP 또는 안전한 API 결과 코드만 표시하도록 보완했습니다.
- 포토코리아 키는 일반/Decoding 원문을 지원합니다. Encoding된 키의 %xx가 들어간 경우에도 한 번 정규화한 뒤 전송하도록 해 이중 인코딩을 줄였습니다. 실제 포털 인증 성공은 본인 키로 확인해야 합니다.

## 스크롤 유지
- 검색 제외·제외 해제·사진 승인/제외·대기열 갱신은 전체 페이지 이동 없이 POST 결과의 main 영역만 갱신합니다.
- CSRF 필드와 클릭한 버튼 값을 전달합니다. 최근 기록의 클릭한 행을 같은 화면 높이에 유지하고 포커스 이동 시 스크롤을 방지합니다.
- 중복 제출을 막고 오류·로그인 만료 시 결과를 확인하도록 표시합니다. JS가 꺼져 있으면 기존 HTML 폼 동작을 유지합니다.

## 적용 후 확인할 것
1. 긴 목록 아래쪽에서 검색 제외→제외 해제를 눌러 페이지 맨 위로 올라가지 않는지 확인합니다.
2. 대기열 갱신 후 새 검색 기록에 두 국내 출처의 응답이 나오는지 확인합니다.
3. 김치 양파 국 등 새 음식 검색에서 LLM 대표명 또는 기본 김치국 검색어를 확인합니다.
4. 사진 후보를 제외한 뒤 READY로 바뀌고 같은 주소가 다시 나오지 않는지 확인합니다.

## 검증 범위
- 변경 Java 파일 최소 Spring/JDBC/Jackson 스텁 컴파일, 대표명/조리법/핵심어/원문 삭제 제약과 모델 비활성 fallback 검사 통과.
- 실제 식품안전나라 샘플 메타데이터 처리·제외 사진 필터, 포토코리아 단일 응답 fixture·Encoding/Decoding 키 처리 검사 통과.
- JS 모의 DOM 검사: 제출 값·CSRF 전달, 행 기준 스크롤 유지, preventScroll 포커스, 오류·로그인 만료 처리 통과.
- JS 문법 검사 통과. 전체 Gradle 빌드, 실제 MySQL V21/트랜잭션, Windows 브라우저 및 실제 로컬 LLM 추론 확인은 사용자 PC에서 필요합니다.
