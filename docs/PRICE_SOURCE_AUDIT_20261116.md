# SmartNF 식재료 가격 출처 종합 검증

검증일: 2026-11-16, 한국시간. 공개 문서·공개 HTTP 응답·실제 브라우저 상품 화면을 구분하여 기록했습니다.

## 1. 결정에 필요한 결론

1. **쇼핑하우 v7 검색 JSON은 실제 동작합니다.** 양파·달걀·쌀·우유·돼지고기 모두 HTTP 200, 응답 code 200, 각각 25개 결과를 반환했습니다. 앞서 다른 API 주소의 오류로 검색 기능 전체를 판단한 설명은 정정합니다.
2. **검색 결과의 최저가가 누구나 결제할 수 있는 기본 판매가는 아닙니다.** 양파와 달걀의 판매처 화면에서 쿠폰 적용가임을 확인했습니다. 최종 결제는 하지 않았습니다.
3. **공개 응답 성공과 운영 이용 허용은 별개입니다.** 쇼핑하우의 일반 크롤러 제한, 다나와·에누리·오아시스의 재사용 관련 약관, 다나와 MCP의 접속 제한을 함께 확인했습니다. 이 검증으로 자동 수집·DB 저장·재게시 전체를 무조건 허용한다고 확정한 상업 사이트는 없습니다. 법적으로 모두 불가능하다는 뜻도 아닙니다.
4. **참가격 CSV는 예상 예산용으로 이용 조건과 실제 다운로드를 확인한 출처입니다.** 현재 구매 가격과 혼합하면 안 됩니다.
5. 현재 바로 구체화할 수 있는 범위는 **참가격 예상 예산 + 공개 가격비교/판매 상품 페이지 연결 + 사용자가 확인한 구매 상품 기록**입니다. 외부 자동 수집은 출처별 이용 조건이 확인된 범위에 맞추어 활성화해야 합니다.

## 2. 판정 기준과 범위

| 판정 | 의미 |
|---|---|
| 자동 연동 가능 | 기술적 접근, 신청 자격, 이용 범위가 현재 용도에 맞게 확인됨 |
| 승인·제휴 또는 이용 조건 확인 필요 | 데이터나 연동 경로는 있으나 자동 수집·저장·제공에 조건이 남음 |
| 사이트 연결 가능 | 공개 상품/비교 화면으로 안내 가능. 데이터 복제 허용을 뜻하지 않음 |
| 현재 검증 불가·미완료 | 자료·권한·응답 또는 판매처 대조가 부족함. 불가능으로 단정하지 않음 |

검증 범위는 10개 출처의 접근 방식·상품 표시·가입/승인·기술/약관 조건입니다. 쇼핑하우는 5개 검색어를 실제 호출했습니다. 다나와·에누리·오아시스는 5개 품목군의 공개 검색/상품 표본을 확인했습니다. 마트 전단은 제한된 행사 품목이므로 5개 품목이 항상 존재하는 검색 서비스로 취급하지 않았습니다. 11번가·쿠팡의 인증 API는 적격 키가 없어 5품목 인증 호출을 실행하지 않았습니다. **50개 조합의 최종 결제가격까지 모두 검증한 결과가 아닙니다.**

## 4. 쇼핑하우 실제 5품목 검색 결과

직접 요청 구간: 한국시간 약 11:40~11:41. 주소: `https://shoppinghow.kakao.com/v7.0/product/search.json?q=검색어` (검색어 URL 인코딩).

핵심 필드: `middleProdlist.data`, `productId`, `productName`, `bundleName`, `priceMin`, `priceModifiedTime`, `unitTotalCapacity`, `unit`, `mallList[].name`, `mallList[].price`, `mallList[].delivery_price`, `mallList[].link`.

빈 `delivery_price`를 무료배송으로 바꾸면 안 됩니다. `priceAddDelivery` 같은 대표 필드만 신뢰해서도 안 됩니다. 우유 표본에서 대표금액과 판매처 배송비를 함께 확인해야 했습니다. 수정 시각 필드의 의미·시간대는 공식 계약이 없어 확정하지 않았으며, 수집 시각과 구분합니다.
