# 참고 재료 압축 표시·음식 계열 정렬 패치

2026-11-03 / 직전 `SmartNF_RECIPE_FILTER_UPDATE.zip` 적용 프로젝트 기준.

1. 서버 종료 후 ZIP의 `src/`, `docs/`를 프로젝트 루트에 그대로 덮어쓴다.
2. `bash run_local.sh` 실행 → 브라우저 Ctrl+F5.
3. 음식·조리·가공에서 제목과 음식 계열의 높이 정렬을 확인한다. 모바일에서는 제목 아래에 배치된다.
4. 참고 레시피 있는 음식(예: 해물칼국수)을 담고 참고 레시피의 재료를 연결한다.
5. 아래 ‘선택한 식재료’의 음식별 참고 재료에서 제외할 재료를 누른다. 색상/테두리/✓와 제외 개수가 바뀌며, 다시 누르면 선택이 취소된다.
6. **선택 재료 제외 (N)**을 눌러 반영한다. 선택만으로 바로 해제되지 않는다. **이 음식의 레시피 연결 해제**는 음식의 전체 참고 연결을 지우는 별도 기능이다.

재료를 위아래로 반복하지 않고 한 번만 표시한다. 원문의 수량과 서로 다른 음식별 연결, 개별 식재료 선택은 유지한다. 모든 재료를 제외해도 참고 레시피 연결은 유지된다. 계정/영양 계산 미연결·이 화면 한정 임시 유지 범위는 기존과 같다.

DB 마이그레이션·npm 설치·데이터 재생성은 필요 없다. 변경/보안/검증 내용은 `SmartNF_IMPROVEMENTS.md` 128절에 기록했다. Node/보안 JS20개와 Chromium PC·모바일 검증 완료. 실제 서버 구동은 적용 후 확인한다.
