# 식생활 직접 활용 도구 — 적용 및 확인

## 적용
ZIP을 smartnf 프로젝트 루트에 덮어쓰기 → 서버 재시작 → Ctrl+F5. 이번에는 건강정보 설치 스크립트 재실행/신규 키 신청 불필요. 기존 /js/data/food-nutrition/manifest.json 및 버전 데이터가 있어야 식품·메뉴 검색이 작동한다.

## 확인 순서
1. 건강 식생활 관리 가이드의 ‘장보기 · 성분 비교’에서 간장 검색. 성분 확인·비교 담기를 클릭하고 원본 기준/출처와 비교표 확인. 다른 양념도 최대4개 담기. 50g 입력 시 각 성분이100g의 절반인지 확인. 비교 제외 버튼으로 제거.
2. ‘조리 · 재료와 양념’에서 부추 검색 → 상세 열기. 실제 재료·양념 중량/조리 단계 확인. g 단위 양념이 있는 레시피에서 변경 양 입력 → 중량 차이만 확인. 실제 영양 변화/치료 적정량은 계산하지 않는다.
3. ‘외식 · 메뉴 정보’에서 비빔밥 검색 → 메뉴 상세 보기. 100g 성분과 원본 분량/출처 기준일 확인. 재료/양념/조리법 미제공 상태 확인. 일반 요청과 실제 음식점 가능 여부 구분.
4. 건강정보에 알레르기를 적용한 경우, 확인 불가 복합 레시피/외식 메뉴가 안내 보류되는지 확인.

## 현재 가능한 것과 부족한 것
- 가능: 보유 영양값 직접 비교, 레시피 실제 재료/양념/단계 제공, 입력 양념 중량차 비교, 메뉴 원본 영양과 출처 표시.
- 부족: 개별 매장 실제 재료·소스·조리법/조절 가능 여부, 전체 문화권 분류 검토, 인분·영양 단위 검증, 조리손실·수율, 양념 변경 후 완성식 영양량. 없는 정보를 AI 생성으로 채우지 않는다.
- 음식DB 전체에는 업체/가공 제품 등 여러 자료가 있어 검색 결과를 모두 동일한 표준 외식메뉴라고 취급하지 않는다. 원본 식품기원 표시를 확인한다.
- 비교 도구는 임시이며 식품 선택·추가확정·MyPage 저장과 별개. 레시피 검색은 명칭 검색이며 선택 재료 코드와 연결이 검토된 추천은 아니다.

## 추가 확보처 확인 (2026-10-26)
- [공공데이터포털 통합 식품영양 표준데이터](https://www.data.go.kr/data/15100064/standard.do): 원재료·가공식품·음식의 영양성분과 기준량·자료원 필드를 제공. 실제 음식점의 상세 양념 배합을 이 목록만으로 확보할 수 있다고 가정하지 않음.
- [식약처 영양 API 메타데이터](https://www.data.go.kr/catalog/15127578/openapi.json): 영양·출처·분량·업체 등의 제공 범위를 확인. 이번에는 신규 키/대량 호출 없이 기존 보유 DB 재사용.
- [공식 레시피 API 명세](https://www.foodsafetykorea.go.kr/api/newDatasetDetail.do?svc_no=COOKRCP01): 중량(1인분) 필드가 있으나 기존 수집자료의 공란과 영양 기준 검토가 남아 있음. 명세에 필드가 존재하는 것과 모든 레시피에 값이 있다는 것은 다름.
- 매장별 실제 재료·소스·변경가능 여부는 공개된 매장 자료 또는 제공처 협의가 필요. 공식 페이지에 없으면 미확보 유지. 원산지 국가 필드를 음식 문화권으로 전용하지 않음.
